# 网易公开课搜索

## 执行入口

- Adapter：`scripts/open163/adapter.py`
- 搜索脚本：`scripts/open163/open163_search.py`
- 第三方依赖：无，仅使用Python标准库
- 认证：通常不需要；可选 `OPEN163_COOKIE`
- 计划参数：当前只使用关键词和 `max_results`

## 搜索路径

请求服务端渲染页面：

`https://open.163.com/newview/search/{keyword}`

脚本使用课程详情链接中的`pid`划分结果块，解析课程标题、封面、简介、课时数、播放量和付费标记。搜索页是单次HTML请求，当前实现不翻页；直接脚本默认20条并按`max_results`截取。

## 输出和错误

结果以pid作为标识，返回课程详情页、标题、描述、封面、课时、播放量和付费状态。旧脚本会生成自身质量估计，Adapter只保留允许的平台原生信号，不生成Selector最终评分。

页面请求失败、没有pid链接或HTML结构变化时，脚本可能返回空结果并以非零状态退出；Adapter应将其记录为执行或解析错误，而不是伪造课程。

搜索入口不读取视频流、不下载课程，也不执行资源质量筛选。

## 当前验证状态

代码包含公开页面解析和离线解析测试能力；本轮尚未完成当前页面结构下的真实搜索验收。连续空结果时应检查搜索页是否仍为服务端渲染以及`pid`链接格式是否变化。
