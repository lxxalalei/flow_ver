# 一席搜索

## 执行入口

- Adapter：`scripts/yixi/adapter.py`
- 搜索脚本：`scripts/yixi/yixi_search.py`
- 认证：无用户认证要求
- 计划参数：当前只使用关键词和 `max_results`

## 搜索路径

第一版调用一席网页客户端使用的公开 JSON 搜索接口，使用网页公开的固定客户端请求头，不读取用户 Cookie 或登录态。返回一席演讲、记录、枝桠和花絮中的公开视频候选，忽略讲者主页、合集和暂时无法构造稳定详情页的节目类型。

结果包含标题、简介、讲者、封面、观看数和一席详情页。搜索只发现公开页面，不解析播放流、不登录、不下载视频。

## 适用范围

适合人文、社会、科学、自然、艺术、教育、成长经历和人物故事等演讲内容。多数内容面向成人或具备一定理解能力的青少年，儿童适龄性由 Selector 判断。它不替代系统课程、短步骤演示或同步学习材料。

## 错误

- 请求超时：`NETWORK_TIMEOUT`
- HTTP 或连接失败：`NETWORK_ERROR`
- 接口结构变化或客户端请求头失效：`PARSE_FORMAT_NOT_SUPPORTED`
