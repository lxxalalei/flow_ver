# 资料库结构详细规范

> 本规范定义了学习资料库的目录结构、命名规则、文件组织方式等详细标准。

## 根目录

### 默认位置

```
学习资料库/
```

### 可配置性

根目录位置可以根据用户需求调整，但内部结构保持一致。

---

## 一级目录：学习领域/学科

### 标准分类

| 目录名 | 包含内容 | 示例 |
|--------|---------|------|
| 数学 | 所有数学相关资源 | 计算、几何、应用题、奥数等 |
| 语文 | 所有语文相关资源 | 拼音、识字、阅读、写作等 |
| 英语 | 所有英语相关资源 | 启蒙、单词、阅读、听力等 |
| 科普 | 科学普及类资源 | 恐龙、宇宙、自然、实验等 |
| 编程 | 编程和科技类资源 | Scratch、Python、机器人等 |
| 艺术 | 艺术和手工类资源 | 画画、音乐、手工、舞蹈等 |
| 综合主题 | 跨学科主题资源 | 节日、职业认知、安全教育等 |
| 待确认 | 分类不明确的资源 | 暂时无法准确分类的 |

### 命名规则

- 使用中文通用名称
- 两个字到四个字为宜
- 不要使用英文缩写
- 保持一致性，不要一会儿"数学"一会儿"Math"

### 新增分类原则

只有当某类资源积累到一定数量（比如10个以上），才考虑新增一级分类。不要为了一两个资源就新建分类。

## 二级目录：学段/适龄

### 按年级分类

适用于同步教材的资源：

```
小学一年级/
小学二年级/
小学三年级/
小学四年级/
小学五年级/
小学六年级/
初中一年级/
...
```

### 按年龄分类

适用于启蒙类、不分年级的资源：

```
0-3岁/
3-6岁/
6-8岁/
8-10岁/
10-12岁/
```

### 全龄通用

不分年龄段的通用资源：

```
全龄通用/
```

### 分类选择原则

**优先按年级：**
- 同步教材的练习题、课件
- 明确标注年级的资源
- 学校学习相关的内容

**优先按年龄：**
- 启蒙类、绘本类
- 科普、兴趣类
- 没有明确年级标注的

**全龄通用：**
- 工具书、百科全书
- 经典绘本、故事
- 方法类、工具类资源

## 三级目录：主题/资源类型

### 主题分类

按知识点或主题分类：

```
四则混合运算/
拼音启蒙/
恐龙科普/
Scratch入门/
```

### 资源类型分类

按资源形式分类：

```
练习题/
绘本/
视频/
课件/
音频/
```

### 选择原则

**主题优先：**
- 资源数量多，按主题细分
- 同一主题下有多种类型的资源

**类型优先：**
- 资源数量少
- 同一类型的资源放一起

**混合使用：**
- 先按大主题分
- 主题下再按类型分
- 或者反过来

### 粒度控制

**不要太细：**
- ❌ "两位数加法进位练习题"
- ✅ "加减法练习"

**不要太粗：**
- ❌ "数学"（这是一级分类）
- ✅ "计算练习"

**合适的粒度：**
- 一个目录下有 3-20 个资源为宜
- 太少就合并，太多就细分

**什么时候可以省略：**
- 只有一个来源
- 来源不重要
- 资源本身已经很明确

## 文件命名规范

### 命名格式

```
[来源]-[资源名]-[版本/日期].[扩展名]
```

### 示例

```
K5Learning-三年级混合运算-2024.pdf
B站-高思导引四则运算-第1讲.mp4
学科网-四年级数学期末试卷-人教版.docx
国家中小学智慧教育平台-三年级数学下册-第1单元.mp4
```

### 命名原则

1. **有意义**：一看文件名就知道是什么
2. **包含来源**：便于追溯和比较
3. **包含关键信息**：年级、知识点、版本等
4. **避免特殊字符**：不要用空格、问号、冒号等
5. **用中文**：和目录保持一致

### 常见资源类型命名

**练习题：**
```
[来源]-[知识点]练习题-[年级/版本].pdf
```

**视频：**
```
[来源]-[标题]-[第X讲/集].[扩展名]
```

**绘本：**
```
[书名]-[作者/出版社].[扩展名]
```

**音频：**
```
[专辑名]-[第X集]-[标题].[扩展名]
```

## 附属文件处理

### 图片资源

放在同级的 `images/` 子目录：

```
四则混合运算/
├── 练习题.md
└── images/
    ├── 图1.jpg
    └── 图2.jpg
```

### 答案解析

和题目文件放一起，命名对应：

```
K5Learning-三年级混合运算-题目.pdf
K5Learning-三年级混合运算-答案.pdf
```

或者：

```
K5Learning-三年级混合运算.pdf
K5Learning-三年级混合运算-答案解析.pdf
```

### 相关文件

同一资源的多个文件放同一目录：

```
高思导引-四则运算/
├── 视频-第1讲.mp4
├── 视频-第2讲.mp4
├── 讲义.pdf
└── 练习题.pdf
```

## 隐藏目录和文件

### .library 目录

资料库的元数据和索引，放在隐藏目录：

```
学习资料库/
└── .library/
    ├── index.json           // 主索引
    ├── tags.json            // 标签索引
    ├── config.json          // 配置文件
    └── logs/                // 操作日志
        ├── 2024-01.log
        └── 2024-02.log
```

### 为什么用隐藏目录

- 和用户资源分开，不干扰
- 用户一般不需要直接操作
- 保持用户可见的目录干净整洁

## 待确认目录

### 什么时候用

分类证据不足时，先放入 `待确认/` 目录：

- 不确定属于哪个学科
- 不确定适龄范围
- 不确定主题分类
- 内容质量不确定

### 目录结构

```
待确认/
├── [资源名]/
│   ├── 资源文件
│   └── .meta.json          // 记录分类疑问
└── ...
```

### 元数据记录

记录分类疑问，便于后续整理：

```
{
  "title": "资源标题",
  "classification_doubts": [
    "不确定是数学还是科普",
    "不确定适合几年级"
  ],
  "suggested_categories": [
    "数学/小学三年级/",
    "科普/6-8岁/"
  ],
  "added_time": "2024-01-01"
}
```

### 定期整理

建议定期（比如每月）整理待确认目录：
- 能确定分类的 → 移动到正确位置
- 确实无法分类的 → 保留但记录原因
- 没用的 → 删除

## 分类调整原则

### 什么时候需要调整

1. **资源数量变化**
   - 某个目录资源太多 → 细分
   - 某个目录资源太少 → 合并

2. **使用反馈**
   - 用户经常找不到 → 调整分类逻辑
   - 某个分类很少用 → 考虑合并

3. **新的资源类型**
   - 出现新的学科/类型 → 新增分类
   - 旧的分类不再适用 → 调整

### 调整步骤

1. 分析现有结构的问题
2. 设计新的分类方案
3. 移动文件
4. 更新索引
5. 验证正确性

### 注意事项

- 调整前备份
- 调整后更新所有索引
- 尽量保持向后兼容
- 大的调整要告知用户

## 多设备同步（可选）

如果用户需要多设备同步：

### 同步方案

- 使用云盘同步（百度网盘、iCloud、OneDrive等）
- 只同步资源文件，不同步索引
- 或者索引也同步，但要处理冲突

### 注意事项

- 索引文件可能有冲突
- 大文件同步慢
- 隐私和安全考虑

---

## 备份策略

### 定期备份

建议定期备份资料库：
- 完整备份：每月一次
- 增量备份：每周一次
- 重要资源：随时备份

### 备份内容

- 所有资源文件
- 索引和元数据
- 配置文件

### 备份位置

- 本地备份：外接硬盘
- 云端备份：云存储服务
- 多地备份：更安全

---

## 存储空间管理

### 空间不足时的处理

1. **清理重复资源**
   - 找出内容重复的
   - 保留质量最好的
   - 删除其他的

2. **删除低质量资源**
   - C级资源可以考虑删除
   - 很久没用的资源
   - 质量不好的资源

3. **压缩不常用的**
   - 很久不用的资源打包压缩
   - 需要时再解压

4. **扩展存储空间**
   - 换更大的硬盘
   - 使用云存储

---

## 最佳实践总结

1. **结构清晰**：层级不要太深，3-4层为宜
2. **命名一致**：同样的东西用同样的名字
3. **由粗到细**：先大分类，再慢慢细分
4. **灵活调整**：根据实际使用情况优化
5. **文档记录**：分类规则要有记录
6. **定期整理**：保持资料库整洁有序
