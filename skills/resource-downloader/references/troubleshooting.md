# 故障排除与常见问题

本文档汇总下载过程中可能遇到的问题和解决方案。

---

## 🎬 视频下载问题

### 问题1：yt-dlp 下载失败，提示 403 错误

**症状**：
```
ERROR: [bilibili] BV123456789: Unable to download webpage: HTTP Error 403: Forbidden
```

**可能原因**：
1. B站反爬机制触发
2. 请求太频繁
3. IP 被临时限制

**解决方案**：
1. **等一会儿再试**：通常等几分钟到几小时就恢复了
2. **降低下载频率**：批量下载时加延迟
3. **使用 cookie**：如果有登录账号，可以导出 cookie 使用
4. **换个网络环境**：如果 IP 被封，换个网络试试

---

### 问题2：下载的视频没有声音

**症状**：视频能看，但没有声音

**可能原因**：
- 视频流和音频流是分开的，没有合并成功

**解决方案**：
1. **检查 ffmpeg 是否安装**：
   ```bash
   which ffmpeg
   ```
   如果没有输出，说明没装，需要安装。

2. **手动合并音视频**：
   ```bash
   ffmpeg -i video.mp4 -i audio.m4a -c:v copy -c:a aac output.mp4
   ```

3. **重新下载，指定合并格式**：
   ```bash
   yt-dlp --merge-output-format mp4 <链接>
   ```

---

### 问题3：播放列表只下载了第一个视频

**症状**：明明是播放列表，但只下了第一个

**解决方案**：
1. **加上 -i 参数**：
   ```bash
   yt-dlp -i <播放列表链接>
   ```

2. **确认链接是播放列表页**：
   - ✅ 正确：`https://www.bilibili.com/medialist/play/ml123456`
   - ❌ 错误：单个视频的链接

3. **加上 --yes-playlist 参数**：
   ```bash
   yt-dlp --yes-playlist <链接>
   ```

---

### 问题4：下载速度特别慢

**可能原因**：
1. 网络带宽限制
2. 服务器限速
3. 高峰期拥堵

**解决方案**：
1. **降低视频质量**：文件更小，下载更快
   ```bash
   yt-dlp -f 'bestvideo[height<=480]+bestaudio' <链接>
   ```

2. **换个时间下载**：避开晚上高峰期

3. **使用多线程**（如果支持）：
   ```bash
   yt-dlp -N 4 <链接>  # 4个线程
   ```

4. **检查网络连接**：确认网络本身没问题

---

### 问题5：字幕下载失败

**症状**：加了 --write-sub 但没有字幕文件

**可能原因**：
1. 视频没有字幕
2. 字幕语言不存在
3. 字幕是自动生成的

**解决方案**：
1. **查看有哪些字幕可用**：
   ```bash
   yt-dlp --list-subs <链接>
   ```

2. **下载自动生成的字幕**：
   ```bash
   yt-dlp --write-auto-sub --sub-lang zh-CN <链接>
   ```

3. **指定字幕语言**：
   ```bash
   yt-dlp --write-sub --sub-lang zh-CN,en <链接>
   ```

## 📄 文件下载问题

### 问题6：wget 下载的文件不对

**症状**：下载下来的不是预期的文件，可能是个 HTML 页面

**可能原因**：
1. 链接有重定向
2. 需要登录才能下载
3. 链接是个网页，不是直链

**解决方案**：
1. **跟随重定向**：
   ```bash
   wget --content-disposition <链接>
   ```

2. **用 curl -L**：
   ```bash
   curl -L -O <链接>
   ```

3. **检查链接是否是直链**：
   - ✅ 直链：`https://example.com/file.pdf`（后缀是 .pdf）
   - ❌ 网页：`https://example.com/download?id=123`（需要跳转）

---

### 问题7：下载到一半断了，怎么办？

**好消息**：wget 和 yt-dlp 都支持断点续传！

**wget 断点续传**：
```bash
wget -c <链接>
```

**yt-dlp 断点续传**：
```bash
yt-dlp -c <链接>
# 或者直接重新运行命令，默认会续传
```

**注意**：
- 必须在同一个目录下运行
- 文件名要一致
- 如果服务器不支持断点续传，就只能重新下

---

### 问题8：下载的文件损坏/打不开

**可能原因**：
1. 下载不完整
2. 传输过程中损坏
3. 文件本身就有问题

**解决方案**：
1. **检查文件大小**：和预期的差不多吗？
2. **重新下载**：用断点续传或者重新下
3. **检查文件格式**：
   ```bash
   file 文件名
   ```
   看看是不是正确的格式

4. **换个来源**：如果文件本身有问题，找别的链接

## 🌐 网页转换问题

### 问题9：转出来的 Markdown 很乱

**可能原因**：
1. 网页结构复杂
2. 有很多广告和无关内容
3. 编码问题

**解决方案**：
1. **先提取正文再转换**：用 readability 之类的工具先提取正文
2. **手动清理**：转换后手动清理一下无关内容
3. **用专门的工具**：比如 html2text、pandoc 试试不同的工具

---

### 问题10：转 PDF 失败

**可能原因**：
1. wkhtmltopdf 没装
2. 网页太复杂
3. 字体问题

**解决方案**：
1. **检查 wkhtmltopdf**：
   ```bash
   which wkhtmltopdf
   ```

2. **用 pandoc 试试**：
   ```bash
   pandoc input.html -o output.pdf
   ```
   （效果可能一般，但至少能转）

3. **用浏览器打印**：如果有浏览器的话，用打印功能保存为 PDF 效果最好

## 🔧 工具相关问题

### 问题11：yt-dlp 版本太旧，很多网站不支持

**解决方案**：更新 yt-dlp

```bash
# 更新 yt-dlp
yt-dlp -U

# 或者用 pip 更新
pip install -U yt-dlp
```

**建议**：定期更新，因为网站经常变，yt-dlp 也要跟着更

---

### 问题12：ffmpeg 找不到

**症状**：yt-dlp 提示找不到 ffmpeg

**解决方案**：
1. **检查是否安装**：
   ```bash
   which ffmpeg
   ```

2. **如果没装，安装一下**：
   ```bash
   # Ubuntu/Debian
   sudo apt install ffmpeg
   
   # CentOS/RHEL
   sudo yum install ffmpeg
   
   # Mac
   brew install ffmpeg
   ```

## 🚫 下载不了的情况

### 哪些情况真的下载不了？

1. **付费墙后面的内容**
   - 会员专享视频
   - 付费课程
   - 需要购买的资料

2. **DRM 加密的视频**
   - Netflix、Disney+ 等流媒体
   - 一些加密的在线课程
   - 有版权保护的视频

3. **严重反爬的网站**
   - 频繁封 IP
   - 复杂的验证码
   - 动态加载且难以解析

4. **链接失效/资源删除**
   - 404 Not Found
   - 视频已删除
   - 文件已过期

### 遇到下载不了的怎么办？

1. **降级方案**：
   - 视频 → 保存网页信息 + 课程目录
   - PDF → 保存网页版内容为 Markdown
   - 付费内容 → 记录信息，等以后有机会再说

2. **标记状态**：
   - ❌ 不可获取：技术上完全不行
   - ⚠️ 待人工辅助：需要用户登录/操作
   - 🔄 转换保存：转成其他格式

3. **找替代资源**：
   - 搜搜有没有其他平台的免费版本
   - 找类似的资源替代

## 📞 遇到问题的排查步骤

按这个顺序排查，通常能解决 80% 的问题：

### 第一步：确认基本信息
- [ ] 链接对吗？复制完整了吗？
- [ ] 网络通吗？能正常上网吗？
- [ ] 工具装了吗？（yt-dlp、ffmpeg、wget 等）

### 第二步：尝试简单方案
- [ ] 重新运行一次命令（有时候就是临时抽风）
- [ ] 等一会儿再试（可能是服务器问题）
- [ ] 换个参数试试（比如降低质量）

### 第三步：深入排查
- [ ] 看错误信息，搜一下是什么意思
- [ ] 检查工具版本，是不是太旧了
- [ ] 试试别的工具行不行（比如 wget 不行试试 curl）

### 第四步：降级处理
- [ ] 原始格式下不了？试试转成其他格式
- [ ] 这个资源不行？找找替代的
- [ ] 实在不行就记录信息，标记为待处理

## 💡 提高成功率的技巧

1. **不要贪多**：一次不要下载太多，容易被封
2. **错峰下载**：避开高峰期，速度快还不容易被封
3. **先试后批量**：先下一个试试，没问题再批量
4. **保持工具更新**：yt-dlp 经常更新，旧版可能用不了
5. **多种方案备用**：一个工具不行，换另一个试试
