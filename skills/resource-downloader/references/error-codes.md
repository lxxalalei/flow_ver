# 统一错误码体系

> 本规范定义了全系统统一的错误码，所有 Skill 在遇到错误时都应使用这些错误码，确保调度层可以统一处理。

## 概述

统一错误码是调度层进行重试、降级、错误处理的基础。
所有 platform skill、downloader、search 在遇到错误时，都必须返回标准错误码，而不是自定义的错误描述。

---

## 错误码分类

| 分类前缀 | 说明 | 典型场景 |
|---------|------|---------|
| `NETWORK_` | 网络相关错误 | 超时、连接失败、DNS 解析失败 |
| `ANTI_CRAWL_` | 反爬相关错误 | 被拦截、验证码、频率限制 |
| `AUTH_` | 认证/登录相关错误 | 需要登录、登录态失效、权限不足 |
| `CONTENT_` | 内容相关错误 | 内容不存在、已删除、付费墙、DRM |
| `PARSE_` | 解析相关错误 | 页面结构变化、解析失败、格式不支持 |
| `DOWNLOAD_` | 下载相关错误 | 下载失败、文件损坏、磁盘空间不足 |
| `SYSTEM_` | 系统相关错误 | 工具缺失、配置错误、未知错误 |

---

## 详细错误码列表

### 网络错误（NETWORK_）

| 错误码 | 说明 | 是否可重试 | 建议重试次数 |
|--------|------|-----------|-------------|
| `NETWORK_TIMEOUT` | 请求超时 | ✅ 是 | 2-3 次 |
| `NETWORK_CONNECTION_FAILED` | 连接失败 | ✅ 是 | 2-3 次 |
| `NETWORK_DNS_FAILED` | DNS 解析失败 | ✅ 是 | 1-2 次 |
| `NETWORK_SSL_ERROR` | SSL 证书错误 | ⚠️ 视情况 | 1 次 |
| `NETWORK_TOO_MANY_REDIRECTS` | 重定向次数过多 | ❌ 否 | 0 次 |

**处理建议：**
- 超时和连接失败：递增延时重试（1s → 3s → 5s）
- DNS 失败：换 DNS 或用 IP 直连
- SSL 错误：可能是代理或证书问题，检查后重试

---

### 反爬错误（ANTI_CRAWL_）

| 错误码 | 说明 | 是否可重试 | 建议重试次数 |
|--------|------|-----------|-------------|
| `ANTI_CRAWL_RATE_LIMITED` | 频率限制，被限流 | ✅ 是 | 1-2 次（加长延时） |
| `ANTI_CRAWL_BLOCKED` | 被反爬系统拦截 | ❌ 否 | 0 次 |
| `ANTI_CRAWL_CAPTCHA` | 需要验证码 | ❌ 否 | 0 次 |
| `ANTI_CRAWL_IP_BANNED` | IP 被封禁 | ❌ 否 | 0 次 |
| `ANTI_CRAWL_NEED_SIGN` | 需要签名/加密参数 | ❌ 否 | 0 次 |

**处理建议：**
- 频率限制：加长请求间隔，降低并发
- 被拦截：停止自动下载并走公开网页或元数据降级
- 验证码/IP 封禁：走降级路径，或提示用户手动操作
- 需要签名：不逆向或规避站点机制，直接降级

---

### 认证错误（AUTH_）

| 错误码 | 说明 | 是否可重试 | 建议重试次数 |
|--------|------|-----------|-------------|
| `AUTH_REQUIRED` | 需要登录才能访问 | ❌ 否 | 0 次 |
| `AUTH_SESSION_EXPIRED` | 登录态已过期 | ✅ 是 | 1 次（重新登录） |
| `AUTH_PERMISSION_DENIED` | 权限不足，无法访问 | ❌ 否 | 0 次 |
| `AUTH_MEMBER_ONLY` | 会员/付费专享 | ❌ 否 | 0 次 |

**处理建议：**
- 需要登录：检查是否有保存的登录态，没有则提示用户登录
- 登录态过期：尝试刷新或重新登录
- 权限不足/会员专享：直接降级或跳过，标注为付费内容

---

### 内容错误（CONTENT_）

| 错误码 | 说明 | 是否可重试 | 建议重试次数 |
|--------|------|-----------|-------------|
| `CONTENT_NOT_FOUND` | 内容不存在或已删除 | ❌ 否 | 0 次 |
| `CONTENT_REMOVED` | 内容已被移除/下架 | ❌ 否 | 0 次 |
| `CONTENT_PRIVATE` | 内容为私有，未公开 | ❌ 否 | 0 次 |
| `CONTENT_PREMIUM_ONLY` | 付费/VIP 专享内容 | ❌ 否 | 0 次 |
| `CONTENT_DRM_PROTECTED` | 有 DRM 版权保护，无法下载 | ❌ 否 | 0 次 |
| `CONTENT_REGION_LOCKED` | 地区限制，当前地区无法访问 | ❌ 否 | 0 次 |
| `CONTENT_NOT_AVAILABLE` | 内容暂时不可用 | ✅ 是 | 1 次（稍后再试） |

**处理建议：**
- 不存在/已删除/私有：直接跳过，从候选中移除
- 付费/DRM：降级处理（提取摘要、保存链接）
- 地区限制：不绕过限制，直接降级并保留来源说明

---

### 解析错误（PARSE_）

| 错误码 | 说明 | 是否可重试 | 建议重试次数 |
|--------|------|-----------|-------------|
| `PARSE_STRUCTURE_CHANGED` | 页面结构变化，解析失败 | ❌ 否 | 0 次 |
| `PARSE_FORMAT_NOT_SUPPORTED` | 不支持的格式 | ❌ 否 | 0 次 |
| `PARSE_EMPTY_CONTENT` | 内容为空 | ✅ 是 | 1 次（可能加载失败） |
| `PARSE_INCOMPLETE` | 内容不完整 | ✅ 是 | 1 次 |

**处理建议：**
- 结构变化：需要更新解析规则，属于 skill 维护问题
- 格式不支持：降级为保存原文件或截图
- 内容为空/不完整：重试一次，可能是网络加载问题

---

### 下载错误（DOWNLOAD_）

| 错误码 | 说明 | 是否可重试 | 建议重试次数 |
|--------|------|-----------|-------------|
| `DOWNLOAD_FAILED` | 下载失败（通用） | ✅ 是 | 2 次 |
| `DOWNLOAD_PARTIAL` | 只下载了部分内容 | ✅ 是 | 1-2 次（断点续传） |
| `DOWNLOAD_FILE_CORRUPTED` | 文件损坏 | ✅ 是 | 1 次（重新下载） |
| `DOWNLOAD_DISK_FULL` | 磁盘空间不足 | ❌ 否 | 0 次 |
| `DOWNLOAD_TOO_LARGE` | 文件过大，超过限制 | ⚠️ 视情况 | 0 次 |
| `DOWNLOAD_SPEED_TOO_SLOW` | 下载速度过慢 | ✅ 是 | 1 次（换源） |
| `DOWNLOAD_DEGRADED_TO_WEBPAGE` | 未取得独立原文件，已保存公开网页正文 | ❌ 否 | 0 次 |
| `DOWNLOAD_NOT_DIRECT_FILE` | 来源 URL 返回网页而不是独立文件 | ❌ 否 | 0 次 |
| `DOWNLOAD_UNEXPECTED_FORMAT` | 下载成功但没有主文件符合计划期望格式 | ❌ 否 | 0 次 |
| `DOWNLOAD_PLATFORM_DEGRADED` | 平台入口只取得公开预览、替代版本或完整文稿 | ❌ 否 | 0 次 |

**处理建议：**
- 通用失败/部分下载：断点续传重试
- 文件损坏：重新下载
- 磁盘不足：提示用户清理空间
- 文件过大：询问用户是否继续，或降级

### 系统错误（SYSTEM_）

| 错误码 | 说明 | 是否可重试 | 建议重试次数 |
|--------|------|-----------|-------------|
| `SYSTEM_TOOL_NOT_FOUND` | 所需工具未安装 | ❌ 否 | 0 次 |
| `SYSTEM_CONFIG_ERROR` | 配置错误 | ❌ 否 | 0 次 |
| `SYSTEM_UNKNOWN_ERROR` | 未知错误 | ✅ 是 | 1 次 |

**处理建议：**
- 工具未安装：检查环境，安装依赖，或降级到其他方式
- 配置错误：需要人工修复
- 未知错误：重试一次，不行就降级

## 错误返回格式

所有 skill 遇到错误时，必须按以下格式返回：

```json
{
  "error_code": "ANTI_CRAWL_BLOCKED",
  "message": "被B站反爬系统拦截，返回412状态码",
  "retryable": false,
  "details": {
    "status_code": 412,
    "url": "https://www.bilibili.com/video/BV1xx",
    "retry_count": 2
  }
}
```

### 字段说明

| 字段 | 类型 | 说明 | 是否必须 |
|------|------|------|---------|
| `error_code` | string | 标准错误码 | ✅ 必须 |
| `message` | string | 人类可读的错误描述 | ✅ 必须 |
| `retryable` | boolean | 当前上下文是否可以重试 | ✅ 必须 |
| `details` | object | 确有诊断价值时提供 | ⚠️ 可选 |

## 处理动作参考

处理动作由收到错误的 Skill 根据错误码、阶段和重试次数决定，不写入通用错误对象。

| 动作 | 说明 | 典型场景 |
|------|------|---------|
| `retry` | 重试一次 | 网络超时、部分下载 |
| `retry_with_delay` | 加长延时后重试 | 频率限制 |
| `change_strategy` | 换策略重试 | 换 UA、换解析方式 |
| `degrade_to_preview` | 降级为预览版 | 完整下载失败，但有预览 |
| `degrade_to_summary` | 降级为摘要 | 预览也没有，只能提取摘要 |
| `degrade_to_link` | 降级为只保存链接 | 完全获取不到，保存地址 |
| `skip` | 直接跳过，不处理 | 内容不存在、付费、DRM |
| `need_user_action` | 需要用户手动操作 | 需要登录、验证码 |

## 重试策略参考

### 重试次数与延时

| 错误类型 | 最大重试次数 | 初始延时 | 递增方式 |
|---------|-------------|---------|---------|
| 网络超时/连接失败 | 3 次 | 1 秒 | 指数递增（1s → 3s → 9s） |
| 频率限制 | 2 次 | 10 秒 | 线性递增（10s → 20s） |
| 部分下载/文件损坏 | 2 次 | 0 秒 | 立即重试（断点续传） |
| 内容为空/不完整 | 1 次 | 2 秒 | 固定延时 |
| 反爬拦截 | 1 次 | 5 秒 | 换策略后重试 |

### 重试停止条件

- 达到最大重试次数
- 错误类型变为不可重试
- 累计耗时超过阈值（比如 5 分钟）
- 用户取消

## 降级路径参考

### 四级降级体系

| 等级 | 级别 | 说明 | 信息完整度 |
|------|------|------|-----------|
| Level 0 | 完整版本 | 原始文件完整下载 | 100% |
| Level 1 | 预览版本 | 预览版/低清晰度/部分章节 | 60-80% |
| Level 2 | 核心摘要 | 目录、简介、核心要点 | 20-40% |
| Level 3 | 来源链接 | 只保存标题、链接、简介 | 5-10% |

### 降级触发条件

- 完整下载失败 3 次以上
- 遇到不可恢复的错误（DRM、付费墙、IP 封禁）
- 用户主动要求降级
- 时间/空间限制
