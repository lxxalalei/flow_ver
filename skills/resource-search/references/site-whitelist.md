# 通用网页搜索站点白名单

本文件只供 `platform=generic` 的通用网页搜索任务生成 `site:` 查询。可优先验证以下来源：

- 国家中小学智慧教育平台：`basic.smartedu.cn`
- 国家教育资源公共服务平台：`eduyun.cn`
- 科普中国：`kepuchina.cn`
- 中国数字科技馆：`cdstm.cn`
- 央视网教育与少儿频道：`cctv.com`

使用规则：

1. 只有站点优势与当前需求相符时才使用，不为凑数量逐站扫描。
2. 站点域名只进入 generic 查询，不得转换成 `smartedu`、`cctv` 等虚构可执行任务。
3. 白名单表示优先发现来源，不代表结果已经通过质量审查；Selector 仍需检查相关性、适龄性、费用和安全性。
4. 用户指定其他可信站点时可以使用其域名，但必须保留为用户约束来源。
