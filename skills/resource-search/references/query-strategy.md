# 查询生成方法

本文件只提供可迁移的查询方法。平台的实际能力和参数以 `../config/platform-catalog.json` 为准。

查询应体现资源的实际使用者。孩子直接使用的查询关注能理解、能参与、能练习、能表达或能实践的内容；家长辅助使用的查询可以关注陪伴方法、资源比较和材料组织。只有在有助于召回时才加入年龄、年级或儿童表达，不把它们当作统一前缀。

## 展开召回角度

从当前需求中选择能产生不同结果的角度：

- 主题组成：可独立检索的概念、现象、人物、过程、问题或实践环节。
- 成长或学习行为：理解、听读、观察、比较、跟做、练习、创作、讨论、表达、习惯养成、情绪支持或查方法。
- 资源形态：讲解、动画、纪录片、音频、图书、文章、互动内容、实验、活动、练习或课程。
- 使用场景：课堂、课后、亲子、通勤、打印或自主学习。
- 来源与格式：在与需求相关时使用机构、站点或文件格式。

这些角度是搜索探索空间，不是固定清单。主题本身已经足够明确时可以直接搜索；增加维度确实能改变召回结果时再加入。

## 按成长领域展开查询

以下模板只在领域匹配时使用。保留用户主题核心，不把模板词当成用户已经提出的限制。

| 领域 | 查询展开方式 |
|---|---|
| 学科与知识 | 主题 + 年级/学段、讲解、练习、知识点、教材版本；只在同步学习确有价值时加入课程平台。 |
| 自然与科学 | 主题 + 原理解释、动画、纪录片、图解、实验、观察任务；可用科技馆、科普机构和纪录片来源。 |
| 阅读与语言 | 主题 + 绘本、分级阅读、故事、朗读、表达训练、共读问题；音频和图书来源通常有价值。 |
| 艺术与创造 | 主题 + 手工、绘画、音乐、创意活动、作品示例、步骤教程；视频演示和活动方案优先。 |
| 情绪与心理 | 主题 + 情绪识别、绘本、亲子沟通、家长指导、儿童心理科普；优先专业或儿童发展机构来源。 |
| 生活习惯与能力 | 主题 + 步骤、清单、打卡、家庭实践、儿童自理、家长陪伴；避免只搜抽象道理。 |
| 安全教育 | 主题 + 官方指南、逃生演练、活动手册、儿童安全、可打印清单；优先官方机构 `site:` 查询。 |
| 社会认知与价值观 | 主题 + 故事、纪录片、博物馆、文化遗产、职业认知、公共规则；适合图书、文博和视频组合。 |
| 运动与健康 | 主题 + 动作示范、儿童健康、营养、睡眠、护眼、注意事项；健康信息优先专业机构来源。 |
| 亲子陪伴 | 主题 + 亲子活动、共读、家庭实验、自然观察、讨论问题、材料准备；优先可执行活动方案。 |

需要权威或机构来源时，读取 `site-whitelist.md`，选择 1-2 个与当前领域最匹配的域名生成 `site:` 查询。

## 适配平台语言

把同一搜索意图改写成平台用户自然使用的表达：

- 视频平台突出需要观看、理解或演示的内容切面。
- 音频平台突出收听、朗读、故事、跟读或连续专辑。
- 方法与经验平台使用真实问题、做法、比较和经验表达。
- 短内容平台聚焦短时间可说明的单个问题或步骤。
- 课程平台使用课程、知识点和学习阶段等有助于站内召回的表达。
- 通用搜索使用主题、内容角度、用途、站点和文件格式发现跨站资源。

平台语言只是表达方式，不是必须追加的关键词后缀。

## 保持查询差异

同一平台的多条查询应改变搜索目标，例如分别覆盖：

- 总览与某个关键子问题。
- 知识理解与亲身实践。
- 原理解释与过程演示。
- 故事沉浸与结构化介绍。
- 直接学习材料与辅助方法。
- **不同资源形态**：同一主题应使用真正适合它的互补形式，不要机械复制固定的课程、文档和练习组合。

仅替换近义词通常不能扩大有效召回，除非平台对不同常用表达确实存在召回差异。

## 互补形态覆盖（必须执行）

没有限定资源形态时，根据主题、目标和使用场景从以下方向中选择真正相关的组合：

1. **讲解与理解**：科普视频、文章、图书、课程或结构化介绍。
2. **故事与沉浸**：纪录片、故事、音频、绘本或人物叙事。
3. **观察与演示**：实验演示、过程记录、案例、地图、图解或实物观察。
4. **动手与实践**：实验、手工、项目、活动方案、观察任务或生活实践。
5. **互动与巩固**：游戏、问答、题卡、练习、模拟或互动工具。
6. **创作与表达**：绘画、写作、音乐、模型制作、讲述或展示任务。
7. **家长辅助**：陪伴方法、讨论问题、资源指南或活动组织建议。

标准模式至少覆盖两个能够产生不同成长或学习体验的方向；宽泛或 exhaustive 需求至少覆盖三个。窄需求只选择有贡献的方向，不为达到数量加入无关查询。

- 根据目标选择平台，不要求每个平台同时承担所有形态。
- 只在结构化教学内容确有价值时选择课程型平台。
- 只在图书、长文、可打印材料或具体文件格式有价值时选择文档来源并使用 `filetype:`。
- 只在练习、测验或巩固任务与当前目标相关时生成练习类查询。
- 用户明确限定形态时遵循该范围；偏好只影响主力方向，不自动排除其他有独特价值的内容。

## 处理约束与推断

- 把用户明确的必须条件保留在相关查询中。
- 把偏好用于增加搜索方向，不必删除其他可能有价值的结果。
- 可以根据主题探索合理的资源形态和学习方式，但不要将其描述为用户指定条件。
- 使用搜索运算符或平台参数前，确认它适用于当前目的并受接口支持。
- 无法在搜索阶段可靠验证的质量、费用、完整性和安全属性，留给 Selector 判断。

## 通用搜索

- 使用 `主题 + 内容角度或用途` 扩大普通网页召回。
- 使用 `site:` 定向与当前需求相关的站点。
- 仅在文件材料确有学习价值时使用 `filetype:`。
- 仅在短语容易被拆散时使用引号。
- 故宫青少年教育资源使用 `site:young.dpm.org.cn`；需要展板、学习手册或教学素材时可加 `filetype:pdf`，例如 `故宫 建筑 学习手册 site:young.dpm.org.cn filetype:pdf`。

同一组 generic 查询的 `params.engines` 必须包含 `duckduckgo`；需要补充中文网页召回时可同时加入 `bing` 或 `baidu`。通常生成 2-3 个互补查询；宽泛需求可以增加角度，窄需求可以更少。

## 国家智慧教育平台搜索

适合结构化课程、同步学习、知识点讲解、课件、讲义和公共教育资源。查询应接近课程目录或教学资源标题，例如 `学段/年级 + 学科 + 知识点`、`课文名 + 朗读/讲解`、`单元主题 + 课程`。只有学段、年级、教材版本来自用户或明显改善召回时才加入，不要虚构版本、册次或筛选条件。

`smartedu` 当前不声明额外搜索参数，查询词本身要承担定位作用。不要发送 `site:`、`filetype:` 或热度词；若需要官网以外的网页、PDF、活动页或长尾资源，交给 `generic`。

## 百度文库搜索

适合发现文档、课件、讲义、练习题、补充材料和可打印资料候选。查询应围绕具体文档材料，而不是泛泛搜索“资源”，例如 `小学数学 分数 练习题`、`古诗词 鉴赏 讲义`、`消防安全 教案 PPT`、`自然观察 活动单`。加入学段、学科、知识点和材料形态，通常能明显改善召回。

不要写“免费下载、VIP、完整下载、无水印”等无法由搜索接口验证的词；免费、完整、可下载和版权风险留给后续筛选或归档阶段判断。百度文库只作为候选发现，不替代官方教材、公共教育平台或机构原始来源。

## Bilibili 搜索

适合视觉讲解、动画解释、实验演示、操作步骤、朗读画面、纪录片和系列课程。查询要说明“要看什么”，例如 `主题 + 动画讲解`、`主题 + 实验演示`、`课文名 + 朗读`、`主题 + 纪录片`、`主题 + 手工教程`。不要只追加“视频”，也不要写“高播放、高赞、优质、精品”等无法由搜索词保证的评价词。

同一主题在 B 站内可以用不同视觉任务区分查询，例如一条找原理动画，一条找实验过程，一条找纪录片或完整讲解。若内容主要依赖文本、音频或官方材料，不要勉强交给视频平台。

## 喜马拉雅搜索

适合朗读、故事、听书、儿歌、跟读、音频课和连续专辑。查询应围绕听觉内容本身，例如 `篇目 + 朗读`、`主题 + 儿童故事`、`主题 + 科普故事`、`主题 + 儿歌`、`主题 + 音频课`。不要搜索依赖图形、步骤观察或实物演示的内容。

需要连续收听、系列故事或专辑时设置 `core=album`；只找单篇朗读、单集故事或具体音频时设置 `core=track`。用户明确要求免费时才设置 `free_only=true`；排序只在确有目的时使用 `sort`，不要用它伪装质量判断。

## 知乎搜索

适合概念背景、差异辨析、资源线索和较深入的专题解释。查询可以写成真实问题或专题表达，例如 `主题 怎么理解`、`主题 有哪些资源`、`主题 和 相近概念 区别`、`儿童学习 主题 如何选择资料`。它主要帮助家长或规划者理解内容，不承担孩子直接使用的学习材料职责。

不要用知乎搜索学习方法、记忆技巧、习惯培养或泛家长经验，除非当前任务明确要求这类讨论。不要把适合课程、视频、音频、活动方案或官方来源的职责转交给知乎。

## 微信公众号搜索

适合补充公众号生态中的机构图文、专题整理、活动方案、课程资源线索和亲子共学材料。查询应像公众号文章标题或专题文章会使用的表达，例如 `主题 + 活动方案`、`主题 + 资料整理`、`主题 + 教学设计`、`主题 + 科普文章`、`主题 + 亲子共学`。不要只用宽泛关键词碰运气，也不要写“爆款、高赞、十万加”等平台热度词。

默认保留搜狗中转链接；只有后续确实需要真实 `mp.weixin.qq.com` 链接时，才在该条搜索的 `params` 中设置 `resolve_url=true`。不要用它搜索学习方法、习惯培养或泛家长经验，除非当前任务明确要收集这类公众号文章。

## 央视网搜索

适合搜索央视公开视频、纪录片、科教节目、少儿节目、安全教育和传统文化节目线索。查询应围绕节目或视频内容表达，例如 `主题 + 纪录片`、`主题 + 科普`、`主题 + 少儿节目`、`主题 + 安全教育`。默认使用视频搜索；只有明确需要音频结果时才设置 `type=audio`，有明确栏目或频道限制时才设置 `channel`。

央视搜索结果常包含新闻片段和栏目页标题。查询要具体到主题和资源形态，避免只用单个宽泛学科词；最终适龄性、完整度和学习价值留给 Selector 判断。

## 科普中国搜索

适合科学现象、自然问题、STEM、天文、生命科学、健康安全等公共科普图文和视频线索。查询应写核心现象、问题或科学主题，例如 `月相`、`火山`、`植物 光合作用`、`昆虫 变态发育`、`近视`。不要写“优质、权威、适合孩子”等评价词；这些留给后续筛选。科普中国站内搜索对过长限定词较敏感，只有明显改善召回时才加入“儿童、青少年、防控”等限定。

如果目标是系统课程、同步学习或练习材料，优先使用 `smartedu` 或 `baiduwenku`；如果需要实验操作过程、动画演示或动手步骤，另开 `bilibili` 等视频方向。科普中国查询负责公共科普解释和可信来源线索。

## 网易公开课搜索

适合公开课、讲座、纪录片和较深入的人文、科学、艺术、社会主题拓展。查询应体现它的深度内容生态，例如 `主题 + 公开课`、`主题 + 讲座`、`主题 + 纪录片`、`主题 + 大师课`。小学同步、短步骤演示或可打印材料通常不优先使用它。

只有当公开课或长视频能提供比短视频、课程平台或网页文章更系统的内容时才生成查询。不要把普通学习任务机械加上“公开课”。

## 微博搜索

适合机构账号发布、活动、展览、竞赛、近期公开资源和时效线索。查询应包含具体机构、活动类型、栏目或近期主题，例如 `机构名 + 活动`、`主题 + 展览`、`主题 + 竞赛`、`主题 + 公开资源`。没有时效性、机构追踪或发布来源价值时不要使用。

微博结果常是线索而不是完整资料。不要用宽泛领域词碰运气，也不要写转评赞、热搜、热门等平台信号词；质量、可用性和来源可信度留给后续筛选。

## 抖音搜索

适合短时间能看清的单个动作、实验现象、操作步骤、生活技能或兴趣引入。查询要窄而具体，例如 `主题 + 做法`、`动作名 + 示范`、`实验名 + 现象`、`手工名 + 步骤`。不适合系统课程、长解释、复杂概念或需要稳定归档的资料。

当前抖音需要认证且容易受验证影响，只有短视频演示对当前目标确有独特价值时才生成任务。不要写热度词，也不要让它承担完整学习路径。

## Anna's Archive 搜索

需要图书、长文、电子书或专业文章时，可以使用 Anna's Archive 补充文档来源。使用自然语言表达，不发送 `filetype:` 运算符。

- 图书搜索（`core=book`）：使用主题及真正需要的内容角度，例如 `火山 儿童科普`、`古埃及文明 图解`、`古诗注释赏析`。
- 文章搜索（`core=article`）：使用 DOI 或关键词搜索学术论文。

只在文档来源能为当前主题提供独特价值时生成 1-2 条查询，与其他平台形成互补。
