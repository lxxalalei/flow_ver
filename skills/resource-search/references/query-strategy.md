# 查询生成方法

本文件只提供可迁移的查询方法。平台的实际能力和参数以 `../config/platform-catalog.json` 为准。

查询应体现资源的实际使用者。孩子直接使用的查询关注能理解、能参与和能练习的内容；家长辅助使用的查询可以关注陪伴方法、资源比较和材料组织。只有在有助于召回时才加入年龄、年级或儿童表达，不把它们当作统一前缀。

## 展开召回角度

从当前需求中选择能产生不同结果的角度：

- 主题组成：可独立检索的知识点、子问题或内容环节。
- 学习行为：理解、听读、练习、观察、跟做、复习或查方法。
- 资源形态：课程、讲解、动画、音频、文章、练习、课件或活动。
- 使用场景：课堂、课后、亲子、通勤、打印或自主学习。
- 来源与格式：在与需求相关时使用机构、站点或文件格式。

这些角度是搜索探索空间，不是固定清单。主题本身已经足够明确时可以直接搜索；增加维度确实能改变召回结果时再加入。

## 适配平台语言

把同一搜索意图改写成平台用户自然使用的表达：

- 视频平台突出需要观看、理解或演示的内容切面。
- 音频平台突出收听、朗读、故事、跟读或连续专辑。
- 方法与经验平台使用真实问题、做法、比较和经验表达。
- 短内容平台聚焦短时间可说明的单个问题或步骤。
- 课程平台使用课程、知识点和学习阶段等有助于站内召回的表达。
- 通用搜索使用主题、内容角度、用途、站点和文件格式发现跨站资源。

平台语言只是表达方式，不是必须追加的关键词后缀。

## 保持查询差异

同一平台的多条查询应改变搜索目标，例如分别覆盖：

- 总览与某个关键子问题。
- 系统学习与单项练习。
- 原理解释与过程演示。
- 连续内容与单个内容。
- 直接学习材料与辅助方法。
- **不同资源形态**：同一主题应在同一平台内用不同查询覆盖视频课程、文档资料和练习题等多种形态，而不是只搜视频。

仅替换近义词通常不能扩大有效召回，除非平台对不同常用表达确实存在召回差异。

## 多形态覆盖（必须执行）

当 Intent 中 `resource_types` 未指定（即用户没有明确说"只要视频""只要试卷"等），Search **必须**确保搜索计划覆盖以下至少三种资源形态：

1. **视频/课程类**：讲解、动画、公开课等可观看的学习内容。
2. **文档/知识点类**：知识点整理、课件、教案、讲义、电子书等可阅读的材料。
3. **练习/试卷类**：练习题、试卷、测试题、练习册等可动手练习的材料。

具体要求：
- bilibili 等视频平台的查询中，至少一条面向"文档/知识点整理"或"练习/试卷"角度（虽然以视频形式呈现，但能引导到文档类资源线索）。
- generic 搜索必须包含面向文档和练习的 `filetype:` 查询（如 `filetype:pdf`、`filetype:doc`、`filetype:ppt`）。
- smartedu 等教育平台应同时搜索课程和练习资源，不限于视频。
- **annas-archive 搜索**：当需求涉及文档/知识点类资源时，必须为 annas-archive 平台生成搜索任务。图书搜索（`core=book`）适合教材、教辅、知识点整理等场景；文章搜索（`core=article`）适合学术论文或专业文章。使用 `主题 + 教材/教辅/注释/赏析/整理` 等自然表达。
- 如果用户明确指定了某种 `resource_types` 或 `format_preferences`（如"只要试卷""找视频"），则按用户指定形态搜索，不需要多形态覆盖。

## 处理约束与推断

- 把用户明确的必须条件保留在相关查询中。
- 把偏好用于增加搜索方向，不必删除其他可能有价值的结果。
- 可以根据主题探索合理的资源形态和学习方式，但不要将其描述为用户指定条件。
- 使用搜索运算符或平台参数前，确认它适用于当前目的并受接口支持。
- 无法在搜索阶段可靠验证的质量、费用、完整性和安全属性，留给 Selector 判断。

## 通用搜索

- 使用 `主题 + 内容角度或用途` 扩大普通网页召回。
- 使用 `site:` 定向与当前需求相关的站点。
- 使用 `filetype:` 查找确有价值的具体文件格式。
- 仅在短语容易被拆散时使用引号。

同一组 generic 查询同时交给百度和 Bing。通常生成 2-3 个互补查询；宽泛需求可以增加角度，窄需求可以更少。

## Anna's Archive 搜索

Anna's Archive 是文档搜索的核心平台，直接搜索图书和文章的全文内容，覆盖 PDF/EPUB/DOC 等多种格式。使用自然语言表达即可，不需要 `filetype:` 运算符。

- 图书搜索（`core=book`）：使用 `主题词 + 教材/教辅/注释/赏析/整理/讲解` 等，如 `古诗注释赏析`、`小学数学知识点整理`。
- 文章搜索（`core=article`）：使用 DOI 或关键词搜索学术论文。

通常为 annas-archive 生成 1-2 条互补查询，与其他平台的文档类搜索形成互补。
