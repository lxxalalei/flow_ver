# 通用搜索站点白名单

本文件供 Skill 构造 `site:` 查询时参考。白名单用于优先发现可信网页、文档、活动方案、稳定资料库和机构资源，不代表这些结果已经通过质量审查。

不是每次搜索都要加 `site:`。只有当需求明确指向某类权威来源，且不加 `site:` 搜索结果质量不足时，才从下表选取站点加入查询。

## 使用方式

在搜索查询末尾追加 `site:域名`，例如 `太阳系 科普 site:cdstm.cn`。一次查询最多加一个 `site:`。如果不确定某个主题该用哪个站点，先不加 `site:` 做宽泛搜索。
