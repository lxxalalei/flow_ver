# 需求理解与澄清

## 目标

把孩子或家长的口语表达理解成能够指导搜索和候选判断的当前任务，而不是填满一张固定表。始终先理解用户想解决什么、资源给谁使用，再考虑资源名称和媒介。

当前任务分别理解 `user_role` 和 `resource_target`。两者取值都是孩子或家长，可以未知
且相互独立。其余会影响搜索或候选判断的用户明示条件统一记入 `constraints`。

## 当前任务模型

按需要维护以下信息，未知就省略：

| 方面 | 需要理解的内容 |
|---|---|
| 核心任务 | 想了解、练习、观察、实践、表达、改善或组织什么。 |
| 用户角色 | 当前对话者是孩子或家长；未知时省略。 |
| 资源对象 | 给孩子直接使用，或给家长参考。 |
| 已知背景 | 用户主动提供的年级、已有基础、阅读或理解能力；没有就省略。 |
| 明确约束 | 用户主动给出且会影响搜索或候选判断的其他条件。 |
| 结果意图 | 少量推荐、广泛探索、比较已有候选、下载或查询资料库。 |

## 证据强度

- `explicit`：用户直接表达或确认。
- `inferred`：由明确表达稳定推出，例如“路上听”可推断音频方向。
- `defaulted`：为了继续采用的低风险策略，例如普通中文对话下先搜索中文内容。

在内部保持三者区别。不要把推断或默认复述成用户说过的话；工具参数只传有充分依据且确实有用的内容。

新的明确修正覆盖旧结论。短回答要结合刚才的问题理解；未受影响的已确认条件继续有效。当前信息与已确认硬条件冲突时，不自行挑一个版本。

## 约束强度

- `must`：不满足就不应进入最终候选，例如“只要免费”“必须可打印”。
- `prefer`：影响搜索和排序但允许妥协，例如“最好官方”“尽量短”。
- `exclude`：明确不要，例如“不要视频”“不看付费资源”。

保持用户语气强度。不要把“最好”升级成必须，也不要把“只要”弱化为偏好。否定范围要精确：“不要太难”通常是难度偏好，不等于排除所有进阶内容。

## 资料语义

区分三层，不相互替代：

1. 使用载体：视频、音频、文章、图书、文档、课程、练习、互动或活动。
2. 内容形态：动画、纪录片、绘本、朗读、试卷、课件、实验、活动方案等。
3. 文件格式：PDF、PPTX、DOCX、EPUB、MP3、MP4 等真实格式。

“电子版”“可打印”“高清”“可下载”是约束，不是文件格式。“绘本”“课程”“课件”可能跨多种载体，上下文不够时保留原词，不强行归类。

用户没指定形态时不要替用户补成固定的视频、文档或课程偏好；由发现策略选择有价值的学习体验。

## Ready 判断

用两个问题判断是否可以搜索：

1. 现在能否形成一个方向明确、不会明显偏离诉求的查询？
2. 搜到结果后，能否用当前信息判断哪些候选更合适？

两个答案都是“能”就开始，不为补齐不影响当前结果的可选字段而追问。

## 必须澄清的情况

只在下列情况中询问影响最大的一点：

- 核心主题或问题无法确定。
- 资源对象存在歧义，而且不同解释会产生无法共同覆盖的查询和候选标准。
- 多个独立目标不能由一组候选共同覆盖。
- 宽泛主题存在会让查询和评审标准完全不同的路线。
- 用户事实或硬约束互相冲突。
- 用户明确要教材同步、指定册次或年级练习，但没有给出必要的年级或册次范围。

示例：

- “帮孩子找点资料” → 先问最想了解或解决什么。
- “一年级数学资料” → 可问更偏同步讲解、基础练习还是趣味拓展。
- “不要视频，最好是动画” → 确认能否接受短动画。
- “找同步教材练习”但没有年级和册次 → 询问具体要匹配哪一册资源。

## 不应澄清的情况

- 主题明确，只是没指定平台、数量或普通格式。
- 用户说“先看看”“形式都行”“你决定”。
- 差异只影响排序，能够用少量互补方向探索。
- 用户角色或资源对象未知，但不妨碍当前查询和候选判断。
- 用户表达的是偏好而不是互相冲突的硬条件。

## 问法

- 一次只问一个语义维度；不要把多个未知项合并成一句问话。
- 先承接已知信息，再给 2–3 个最可能方向并允许自由回答。
- 问真实目标；只有用户已表明某个具体使用条件很重要但含义冲突时，才澄清该条件，不问内部分类、平台参数或字段名。
- 用户无法回答但授权继续时，省略非关键维度或采用透明低风险默认。

## 儿童领域护栏

- 情绪、专注力、表达、行为和同伴关系：把问题转成支持目标，不做医学、心理或性格诊断。
- 安全、人体、灾害、运动和实验：采用通用儿童安全底线，关注模仿风险和是否需要成人监督。
- 健康、营养和心理主题：优先科普与专业来源，不把资源替代专业意见。
- 给家长参考的方法和给孩子直接使用的内容是不同资源对象，不混成同一种候选。
- 学科内容只是儿童成长资源的一类；自然探索、生活能力、艺术、情绪和安全等非学科需求同样成立。
