## 一级目录：成长领域

| 目录名 | 包含内容 |
|---|---|
| 学科与知识 | 学校知识、学科能力、教材同步、练习 |
| 自然与科学 | 自然现象、科学探索、实验观察、科普 |
| 阅读与语言 | 绘本、故事、朗读、分级阅读、表达 |
| 艺术与创造 | 绘画、音乐、手工、舞蹈、创意活动 |
| 情绪与心理 | 情绪识别、心理韧性、自我理解 |
| 生活习惯与能力 | 日常习惯、生活自理、时间管理 |
| 安全教育 | 居家、交通、网络、防灾、身体边界 |
| 社会认知与价值观 | 规则、关系、职业、文化、历史 |
| 运动与健康 | 运动技能、身体健康、营养 |
| 亲子陪伴 | 需要家长组织、共读、共玩的资料 |
| 综合主题 | 横跨多个领域的主题包 |
| 待确认 | 分类证据不足的资源 |

## 二级目录：主题

按资源的具体内容主题命名。示例：`恐龙`、`太空与宇宙`、`分数加减法`、`消防`、`情绪管理`。

粒度适中——不要太细（`两位数加法进位`），也不要太粗（`数学`）。不确定时归"其他"。

## 三级目录：资源格式

固定三个目录，按文件实际格式自动归类：

| 目录 | 扩展名 | 典型内容 |
|---|---|---|
| `视频/` | .mp4 .mov .avi .mkv .webm | 纪录片、动画讲解、课程视频、实验演示 |
| `图文/` | .html .pdf .doc .docx .ppt .pptx .txt .epub .mobi .jpg .png | 书籍、文章、课件、网页归档、绘本、练习 |
| `音频/` | .mp3 .wav .m4a .flac .aac .ogg | 故事、朗读、儿歌、音频课 |

三大格式并列，MCP 根据文件扩展名自动选择，模型不需要指定。

## 文件命名

```
[来源]-[资源名].[扩展名]
```

- `科普中国-恐龙的故事.pdf`
- `B站-太阳系动画讲解.mp4`
- `喜马拉雅-恐龙故事.mp3`

## 归档调用

通过 `resource_archive` 的 `metadata` 传入分类：

```json
{
  "primary_domain": "自然与科学",
  "topics": ["恐龙"],
  "source_name": "科普中国",
  "title": "恐龙的故事",
  "tags": ["科普", "古生物", "低龄友好"]
}
```

MCP 自动构建路径 `自然与科学/恐龙/图文/科普中国-恐龙的故事.pdf`。

## 丰富标签维度

目录管物理组织，标签管精确检索。归档时建议打以下维度的标签：

| 维度 | 示例标签 | 用途 |
|---|---|---|
| 内容特征 | 科普、实验、故事、讲解、活动方案 | 区分内容性质 |
| 使用场景 | 亲子共看、自主学习、课堂使用 | 匹配使用需求 |
| 年龄适宜 | 低龄友好、需家长陪伴 | 补充信息，不做目录 |
| 来源质量 | 官方、专业机构、用户创作 | 来源可信度 |

这些标签通过 `resource_library_search` 的 `tags` 过滤器组合检索。

## 待确认

分类证据不足时归入 `待确认/其他/`，后续整理时重新分类。

## 资料库检索

`resource_library_search` 支持按以下维度过滤：

| 维度 | 字段 | 示例 |
|---|---|---|
| 关键词 | `query` | "恐龙" |
| 成长领域 | `primary_domain` | "自然与科学" |
| 主题 | `topics` | ["恐龙"] |
| 平台 | `platforms` | ["bilibili"] |
| 类型 | `resource_types` | ["video"] |
| 标签 | `tags` | ["科普", "亲子共看"] |
