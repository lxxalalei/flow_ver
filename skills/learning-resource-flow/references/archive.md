# Archive Guidance

归档阶段的语义责任是：**根据真实资源内容决定它应该如何被用户理解和归类。**

文件怎么移动、目录怎么创建、同名怎么处理，由 MCP 负责；Skill 不设计路径规则。

## 1. 什么时候归档

下载已经产生真实文件后，如果用户没有明确表示“只做临时下载/不要整理”，可以继续把文件整理进学习资料库。

归档失败不能反推下载失败；下载和归档是两个不同事实。

## 2. 分类依据

优先根据资源本身的主要学习内容判断主领域，再给出一个自然、具体的主题。

不要根据：

- 文件扩展名；
- 来源平台；
- 用户职业/身份；
- 为了搜索临时提出的探索角度；
- 目录当前有没有某个分类；

去替代资源语义判断。

例如：

- 一个讲“火山喷发原理”的视频 → 主要内容仍是自然科学；
- 一个“如何学习英语单词”的方法课 → 主要内容更接近学习方法，而不是因为例子是英语就机械归到英语；
- 一个跨学科 STEM 项目 → 如果核心就是综合实践，可以归到综合实践，而不是强行拆成多个目录。

## 3. 顶层领域

当前资料库使用以下主要领域：

| domain_id | 语义领域 | 常见主题示例 |
|---|---|---|
| `chinese_language` | 语文与中文 | 拼音、阅读理解、写作、古诗词、文言文 |
| `mathematics_reasoning` | 数学与思维 | 数与运算、几何、应用题、逻辑推理 |
| `english_foreign_languages` | 英语与外语 | 自然拼读、词汇、语法、听说读写 |
| `natural_science` | 自然科学 | 动植物、物理、化学、地球环境、天文与宇宙 |
| `humanities_social_studies` | 人文与社会 | 历史、地理、传统文化、社会常识 |
| `information_technology` | 信息科技 | 计算机、编程、人工智能、网络与安全 |
| `arts_aesthetics` | 艺术与审美 | 绘画、书法、音乐、舞蹈、设计 |
| `physical_health` | 体育与健康 | 运动、健康、营养、安全常识 |
| `learning_skills` | 学习方法与通用能力 | 学习方法、记忆、时间管理、信息检索 |
| `interdisciplinary_practice` | 综合实践与跨学科 | STEM、项目式学习、研究性学习、社会实践 |

`topic` 应描述资源真正围绕的具体学习主题，不需要机械使用示例词。

## 4. 不确定时保持不确定

分类证据不足时不要为了“归档完整”强行猜测，也不要为了一个目录名称额外向用户追问无关信息。

可以进入待分类，之后再整理。

“待分类”比错误分类更可控。

## 5. 不把归档重新做成状态系统

Agent 只负责语义分类和解释最终结果。

不需要关心 Archive ID、AssetBundle、digest、版本链、去重证明、SQLite 状态或手工拼路径。这些都不属于 Skill 的语义职责。
