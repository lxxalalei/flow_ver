# Selector 候选展示

展示目标是让用户基于已知事实做选择，不替资源补写宣传文案。

**展示格式是强制要求**：必须原样使用渲染器 `render_review.py` 的输出，不得改写为 markdown 表格、精简排版或其他自定义格式。渲染器默认按资源类型分组展示。

## 默认格式（按资源类型分组）

```text
共搜索到 {raw_count} 条；精确去重 {dedup_count} 条，过滤 {excluded_count} 条，保留 {candidate_count} 条。
平台异常：{没有则省略}

🎬 视频资源（{count} 条）

1. 🏷️ [A级 · 84分] 标题
   📝 一句话总结资源内容和特点
   🎬 来源：【Bilibili】视频 · 免费
   🔗 https://...

3. 🏷️ [B级 · 70分] 标题
   📝 一句话总结资源内容和特点
   🎬 来源：【Bilibili】视频
   🔗 https://...

🎵 音频资源（{count} 条）

2. 🏷️ [A级 · 80分] 标题
   📝 一句话总结资源内容和特点
   🎵 来源：【Ximalaya】音频 · 免费
   🔗 https://...

📄 文档资源（{count} 条）

...

回复编号选择，例如"1,3"；也可以回复"全部""只要视频"或"取消"。
```

### 分组顺序

视频资源 → 音频资源 → 文档资源 → 习题资源 → 课程资源 → 网页资源

### 分组标题行

`{type_icon} {category_name}（{count} 条）`，后接空行，然后是该组的候选。

## 展示规则

- S：90—100，A：75—89，B：60—74，C：40—59。
- 每条候选固定四行，每行以 emoji 引导：
  1. `🏷️ [等级 · 分数] 标题` — 编号、评分等级和资源标题。
  2. `📝 {summary}` — 模型在 `selector_review.json:data.candidates[].summary` 中生成的一句话总结（不超过50字），描述资源是什么、适合谁或有什么特点。不是截取 description，而是模型理解后的概括。
  3. `{type_icon} 来源：【{platform}】{resource_type} · 免费/付费` — 来源行，type_icon 根据资源类型自动选择（🎬视频 🎵音频 📄文档 ✏️习题 📊课件 📚课程 🌐网页 📌其他）。免费/付费未知时省略。
  4. `🔗 {source_url}` — 资源链接。
- 不再输出"已知信息""推荐依据""注意"等额外行；这些信息保留在 `selector_review.json` 中供后续阶段使用。
- 没有证据的字段直接省略或写"未知"，不要写成"免费""可下载""带答案""适合四年级"。
- `platform_signals` 只转述为播放量、收藏、课时等平台事实，不把它写成质量结论。
- **默认按资源类型分组展示全部候选**；编号必须保持与 `selector_review.json:data.candidates` 一致。
- 平台失败只说明影响，不把"未运行""零结果"和"认证失败"混为一谈。
- **禁止改写渲染器输出格式**：不得用 markdown 表格、列表缩进或其他排版替代标准四行 emoji 格式。
