# Selector 质量评估

只评估已经通过相关性、安全和硬约束过滤的资源。明显不相关、不安全、违反硬约束或缺少基本相关证据的资源直接写入 `excluded`，不要用低分代替过滤。

## 评审原则

先理解当前 Intent，再核验候选证据并进行候选间比较，最后确定等级和展示分数。不要逐项打分、套用固定权重或计算公式。

综合判断时关注以下问题：

- 资源是否真正支持当前成长或学习主题与目标，能否帮助理解、观察、实践、练习、思考、表达、习惯养成、情绪支持或亲子陪伴？
- 内容尺度、表达方式、理解门槛和活动风险是否适合当前使用对象？
- 内容是否清晰、准确且有实质信息，是否完整到足以产生成长价值或学习价值？
- 作者、机构、发布渠道和关键声明是否可信、可核验？
- 访问方式、费用、时长、格式和广告等因素是否影响实际使用？
- 与其他候选相比，它有哪些突出价值、明显不足或不可替代性？

这些问题用于引导整体判断，不是相互独立的评分栏目。根据当前需求决定哪些证据更重要，不要默认所有方向具有固定权重。

## 证据与核验

- 只把标题、摘要、页面简介、目录、预览、作者或机构信息等实际可见内容作为证据。
- 区分已核验事实、平台元数据、标题声明和模型推断；不要把推断写成事实。
- 页面无法访问或关键信息无法确认时，在 `notes` 中明确写出未知项。
- 官方来源能够支持来源可信度，但不自动证明资源相关、适龄、完整或易用。
- 播放、点赞、收藏和平台知名度只能作为辅助信号，不能单独证明准确性、成长价值或学习帮助。
- 标题中的“免费”“全套”“附课件”等内容未经核验时，只能表述为“标题显示”。

## 证据护栏

推荐等级不得超过现有证据能够支持的程度。以下规则是语义护栏，不是分数计算器：

- 只有标题和链接时，不得评为 A 或 S。
- 无法确认资源实际内容时，不得声称其准确、完整或适龄。
- A 和 S 必须有公开页面或足够具体的平台元数据支持核心推荐理由。平台名称、热度、`is_verified` 或宽泛标题单独出现时都不够；至少应能定位作者或发布机构，并确认内容范围、简介、目录或预览中的一项。
- 重要页面无法访问时，将其视为未核验；除非其他可靠证据充分，否则降低推荐等级。
- S 必须是经过候选比较后仍明显突出的少数结果，不要批量授予。
- S 不得存在会改变适用性、安全性或核心成长价值结论的重要未知。
- 证据较弱但具有独特价值的资源可以保留为 B 或 C，并清楚说明局限。

## 候选比较

先比较用途相近的候选，再进行全局排序：

- 优先保留解释更准确、内容更完整、来源更可信且更适合当前孩子或家长使用的资源。
- 识别成长价值或学习价值高度重复的候选，避免同一系列或近似内容占满前列。
- 关注资源之间的互补关系，但不要为了形式多样而牺牲质量。
- 高热度弱内容不得仅凭热度排在低热度高质量内容之前。
- 先形成明确的相对排序，再给等级与展示分数；不要通过独立绝对打分反推排序。

## 等级锚点

| 等级 | 分数 | 判断锚点 |
|---|---:|---|
| S | 90—100 | 公开证据充分，高度适合当前需求，并且与其他候选相比具有突出成长价值 |
| A | 75—89 | 证据较充分，值得推荐，仅有少量不影响主要使用价值的未知 |
| B | 60—74 | 具有实际学习价值，但内容、来源、适龄性、完整性或使用条件仍有明显未知或不足 |
| C | 40—59 | 证据较弱；仅在候选不足或具有不可替代价值时保留，并明确说明限制 |
| 排除 | 不赋分 | 不相关、不安全、违反硬约束或缺少基本相关证据，写入 `excluded` |

等级表达综合结论，分数只用于表达最终排序和同等级内的差异。完成全部候选比较后再分配 `quality_score`，确保保留候选使用 40—100 的整数，并按分数降序排列。

写最终理由时，明确指出依据是 Stage 3 元数据还是已核验页面，并写出支持结论的具体事实。不要使用“内容优质”“来源可靠”“适合孩子”这类没有证据落点的泛化理由。语义规则由主 Agent 负责复核，不为迎合字段校验而制造形式化证据。

## 常见误判

- 内容提到相关词语，不代表它真正解释、展示或支持当前成长主题。
- 面向成人的灾难、历史或社会内容，不能只因主题相同就推荐给孩子。
- 趣味短视频不能仅凭播放量代替准确性、完整性和成长价值。
- 搜索结果中的成人影视、博彩或擦边内容必须按儿童安全过滤。
- 同一主题的图书、纪录片、实验活动和互动内容不自动视为重复。
- 音频、图书或活动资料不因不是视频课程而降低等级；只有无法支持当前目标时才降低评价。
