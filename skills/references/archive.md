# Archive Guidance

归档阶段的语义责任是：**根据真实资源内容决定它应该如何被用户理解和归类。**

文件移动、目录创建和同名处理由 MCP 执行；Skill 只提供语义分类。

## 1. 什么时候归档

满足以下任一条件且下载 Job 已经产生真实文件时进入 Archive：

- 用户明确要求归档、整理进学习资料库；
- 原始任务已经包含归档目标；
- 用户确认了下载完成后的归档建议。

下载 Job 真实成功后，即使原任务没有归档目标，也主动给出一句话分类建议——按
第 2 节的规则给出领域与主题（例如“建议归档到 `natural_science` / 火山喷发
原理”），用户确认后执行。同一资源只建议一次；用户表示不需要整理时尊重其结果，
不再重复提议。

下载结果与归档结果分别依据各自真实 Tool / Job 状态说明。

## 2. 分类依据

优先根据资源本身的主要学习内容判断主领域，再给出一个自然、具体的主题。

分类依据依次来自：

1. 资源正文、标题、描述和真实内容；
2. 当前任务中与资源内容直接相关的用途；
3. 已确认的学科、主题或学习目标。

### 主题优先复用，不轻易新建目录

主题按以下优先级选择：

1. 上次归档返回的 `available_topics`（资料库中该领域**已存在**的二级目录，含用户手工整理的）；
2. `resource_archive` Tool 描述中的领域建议主题；
3. 确实都不贴合时才新建，且使用**可复用的主题词**（描述一类资源，如「火山喷发原理」），
   不要用一次性资源名当主题。

例如：

- 一个讲“火山喷发原理”的视频 → `natural_science` / 火山喷发原理；
- 一部动物世界纪录片 → `natural_science` / **动物与植物**（已有主题，直接复用；
  不要新建「动物王国纪录片」这类一次性目录）；
- 一个“如何学习英语单词”的方法课 → `learning_skills` / 词汇学习方法；
- 一个以综合实践为核心的 STEM 项目 → `interdisciplinary_practice` / 对应项目主题。

## 3. 顶层领域

当前资料库使用以下主要领域：

| domain_id | 语义领域 | 常见主题示例 |
|---|---|---|
| `chinese_language` | 语文与中文 | 拼音、阅读理解、写作、古诗词、文言文 |
| `mathematics_reasoning` | 数学与思维 | 数与运算、几何、应用题、逻辑推理 |
| `english_foreign_languages` | 英语与外语 | 自然拼读、词汇、语法、听说读写 |
| `natural_science` | 自然科学 | 动植物、物理、化学、地球环境、天文与宇宙 |
| `humanities_social_studies` | 人文与社会 | 历史、地理、传统文化、社会常识 |
| `information_technology` | 信息科技 | 计算机、编程、人工智能、网络与安全 |
| `arts_aesthetics` | 艺术与审美 | 绘画、书法、音乐、舞蹈、设计 |
| `physical_health` | 体育与健康 | 运动、健康、营养、安全常识 |
| `learning_skills` | 学习方法与通用能力 | 学习方法、记忆、时间管理、信息检索 |
| `interdisciplinary_practice` | 综合实践与跨学科 | STEM、项目式学习、研究性学习、社会实践 |

`topic` 描述资源真正围绕的具体学习主题。

## 4. 证据不足时进入待分类

当现有资源证据不足以支持可靠分类时，使用待分类结果，并保留当前可确认的标题、来源和主题线索供后续整理。

## 5. 面向用户说明归档结果

Agent 只需要说明：

- 哪些真实文件已经归档；
- 归入哪个领域和主题；
- 哪些文件归档失败或仍待分类。

归档内部路径实现和存储状态由 MCP 管理。
