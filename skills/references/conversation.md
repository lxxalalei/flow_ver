# Conversation Guidance

本文件补充资源任务中的需求理解与澄清判断。

## 1. 当前任务吸收会改变决策的信息

优先还原：

- 用户最终想完成什么；
- 资源实际给谁使用；
- 哪些背景会改变内容尺度；
- 哪些条件是 must / prefer / exclude。

未知信息只有在会改变搜索路线、候选判断或获取决策时才进入当前任务判断；其余信息保持未知即可。

例如“我想给孩子找恐龙资料”中，资源对象是孩子，因此候选判断围绕孩子的可理解性和使用价值展开。

## 2. 复用上层背景，并保持语义来源清晰

OpenClaw 当前上下文已经可靠提供与本次对象明确对应的年龄、年级、基础水平或长期偏好，而且这些信息会改变当前决策时，直接复用这些事实。

资源决策中的信息来源保持清晰：

- 上层上下文提供用户与使用对象的已知背景；
- 搜索和 Inspect 结果提供资源事实；
- Agent 为当前召回提出的方向只作为本次探索策略；
- 多对象场景分别绑定各自背景。

## 3. 区分用户事实、合理推断和探索假设

至少区分三类信息：

- **用户明确表达**：例如“先不要视频”“要能打印”；
- **当前表达可稳定推出**：例如“路上听”自然支持音频方向；
- **模型探索假设**：例如用户说“形式你定”，Agent 选择先试动画 + 图文。

新的明确修正覆盖旧推断。must / prefer / exclude 始终保持用户表达的原有强度。

## 4. 澄清标准：答案是否会改变路线

当一个未知答案会让后续去找明显不同的资源，而且已有上下文无法可靠确定时，提出一个信息增益最高的问题。

典型情况：

- “物理启蒙”面向学龄前、小学还是初中；
- “一年级数学资料”更需要同步讲解、基础练习还是趣味拓展；
- 教材同步资料缺少真正影响内容的教材版本；
- 多个孩子背景差异很大，但当前使用对象尚未明确；
- 用户给出的硬约束互相冲突。

当平台、数量、文件格式等信息不会改变当前路线时，由 Agent 根据目标和已有上下文做合理选择。可以通过搜索或 Inspect 直接确认的资源事实直接通过工具补充。用户已经说“你决定”“都可以”“先看看”时，由 Agent 承担相应选择。

高价值澄清完成后，根据当前最佳理解开始搜索，让真实结果帮助判断剩余次要不确定性。

## 5. 区分内容、载体和格式

分别理解：

1. **使用载体**：视频、音频、文章、图书、课程、练习；
2. **内容形态**：动画、纪录片、绘本、朗读、试卷、课件、实验、观察卡；
3. **文件格式**：PDF、PPTX、DOCX、EPUB、MP3、MP4、HTML。

例如：

> 要能打印的鸟类观察卡，最好 PDF。

对应：

- 观察卡：内容形态；
- 可打印：must；
- PDF：prefer。

搜索与候选判断按这三层分别处理，格式偏好保持其原有约束强度。

## 6. 问题驱动请求先还原用户目标

用户描述学习困难时，先理解他希望改善什么结果，再据此寻找资源。

例如：

> 看历史故事记不住人物关系。

可以还原为需要人物关系、时间线或叙事结构辅助材料。

健康、安全、心理等主题会提高来源可信度和内容适配要求；年龄或阶段确实会改变内容安全性或可理解性时，再把这些信息纳入澄清。

## 7. 明确行动意图直接进入对应阶段

“先看看”“先别下载”表示当前处于发现和判断阶段。

“第 2 个帮我下载”“这本书能下的话保存下来”表示获取意图已经明确。资源对象清楚时直接进入真实获取能力；对象仍有歧义时只澄清对象。

## 8. 面向用户的表达

用户通常只需要看到：

- 真正必要的一个澄清问题；
- 有帮助时的一句当前搜索重点；
- 值得选择的候选及差异；
- 重要但尚未确认的事实；
- 用户要求获取后，真实执行结果。

工具实现、内部对象和语义判断结构保留在 Agent 内部。
