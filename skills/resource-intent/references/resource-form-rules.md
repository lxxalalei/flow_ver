# 资料类型、内容形态与文件格式

本规则用于保留用户对“要什么资料”的真实表达。它只做语义归一化，不决定搜索覆盖范围、平台或查询数量。

## 三层语义

| 层级 | 输出字段 | 含义 | 示例 |
|---|---|---|---|
| 资料大类 | `resource_types` | 资源的主要使用方式或内容载体 | 视频类、音频类、文档类、练习类、图文类、图片类、互动类、活动类 |
| 具体形态 | `format_preferences` | 用户实际说出的内容形态 | 动画、教程、纪录片、公开课、试卷、练习册、绘本、课件、思维导图 |
| 文件格式 | `file_formats` | 可下载或交付文件的编码/容器格式 | PDF、PPT、PPTX、DOC、DOCX、EPUB、MP3、MP4、ZIP |

三层可以同时出现，不互相覆盖。`format_preferences` 暂时也是 Search 的兼容输入，因此必须保留用户表达的具体形态，不用大类替换掉它。

## 通用资料形态

| 资料大类 | 常见具体形态或表达 |
|---|---|
| 视频类 | 视频、教程、讲解、课程、纪录片、动画、讲座、公开课、短视频 |
| 音频类 | 音频、故事、朗诵、儿歌、听书、音频课、播客、专辑 |
| 文档类 | 文档、课件、教案、讲义、电子书、知识点整理、学习资料 |
| 练习类 | 练习题、习题、试卷、作业、测试题、练习册、题卡 |
| 图文类 | 百科、指南、图文教程、文章、知识点、经验、方法 |
| 图片类 | 挂图、插画、思维导图、手抄报、范画、图集、卡片 |
| 互动类 | 软件、应用、游戏、题库、互动课程、模拟实验 |
| 活动类 | 实验、手工、活动方案、亲子游戏、实践任务 |

“绘本”“课件”“课程”等词可能跨大类：绘本可以是图文、音频或视频版本；课件可能是文档或互动内容；课程可能是视频、音频或图文。只在上下文能够确定时归纳大类，否则保留具体形态并省略 `resource_types`。

## 文件格式归一化

- 扩展名统一大写，不保留前导点：`.pdf` → `PDF`，`pptx` → `PPTX`。
- 文件格式只记录真实格式：PDF、DOC、DOCX、PPT、PPTX、XLS、XLSX、TXT、CSV、EPUB、MOBI、MP3、M4A、WAV、MP4、WEBM、ZIP。
- “电子版”“高清版”“打印版”“可下载”不是文件格式，按原语气写入约束或使用场景。
- “电子书”是具体内容形态；只有用户明确说 EPUB、MOBI 或 PDF 时才填写 `file_formats`。
- “表格”“课件”“讲义”不是文件格式；不要擅自补成 XLSX、PPTX 或 PDF。

## 状态与证据

| 用户表达 | `resource_types` | `format_preferences` | `file_formats` |
|---|---|---|---|
| “要动画” | `["视频类"]` inferred | `["动画"]` explicit | 省略 |
| “找音频故事” | `["音频类"]` explicit | `["故事"]` explicit | 省略 |
| “要 PDF 鸟类观察卡片” | `["文档类", "图片类"]` inferred | `["卡片"]` explicit | `["PDF"]` explicit |
| “可打印的练习题” | `["练习类"]` inferred | `["练习题"]` explicit | 省略；可打印进入约束 |
| “形式都可以” | `["不限"]` explicit | 省略 | 省略 |
| 未提任何类型 | 省略 | 省略 | 省略 |

由具体形态归纳资料大类时，大类状态使用 inferred，并复用支持归纳的用户原话作为 evidence。不得把归纳结果标成用户直接说过的事实。

## 不在 Intent 中做的事

- 不因为“数学”“恐龙”“古诗”等主题自动填入推荐形态。
- 不规定用户未指定时要覆盖几种类型。
- 不为某种资料类型选择平台。
- 不把 PDF、视频、练习题拼成搜索句。

以上均由 Search 根据明确偏好、约束和主题制定策略。
