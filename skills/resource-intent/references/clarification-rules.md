# Intent 澄清决策与话术规则

## 1. 澄清的唯一目的

澄清是为了避免 Search 搜到另一类资源，不是为了完成问卷。只问“现在不确认就很可能走错方向”的信息。

判断句：

> 如果不问这个问题，是否仍能生成一个合理、可筛选、不会明显偏离用户诉求的搜索计划？

- 能：不问，省略未知槽位，或使用有证据的 inferred、透明默认继续。
- 不能：澄清一个影响最大的点。

## 2. 澄清优先级

### P0：核心学习对象无法确定

必须问：

- “帮我找点学习资源”
- “孩子学习不太好”
- “想提升一下”

问题应让用户描述真实主题或痛点：

- “目前最想解决哪方面的问题？”
- “想找哪个学科或能力方向的资源？”

不要先问年龄、平台或资源形式。

### P0：资源类型模糊导致搜索方向完全不同

"学习资料"是一个泛词，可能指向完全不同的资源形态和搜索方向。当用户说"找资料""找学习资料""找一些材料"但没有指定具体形态，且主题本身不暗示某种类型时，必须澄清。

判断句：

> "学习资料"是否可能同时指向视频课程、练习试卷和知识点文档，而这些方向的搜索策略和平台完全不同？

- 可能指向完全不同的资源类型，且不同类型的搜索策略差异巨大 → 澄清。
- 用户已经说了具体形态（如"试卷""动画""课程"） → 不问。
- 用户说"形式不限""都可以" → 不问，由 Search 多形态覆盖。

问题格式（给出 2-3 个最常见的方向）：

- "你说的三年级数学学习资料，更偏向哪种？比如视频课程讲解、练习试卷和知识点文档？"
- "找语文学习资料，是想要视频讲解、练习题，还是知识点总结材料？"

### P0：语义分叉

一个词对应完全不同路线

根据上下文给出最可能的分叉：

- 编程：Scratch / Python / 机器人编程。
- 英语：听说启蒙 / 自然拼读 / 单词语法 / 绘本阅读。
- 国学：古诗 / 成语 / 经典诵读 / 历史文化。
- 数学不好：计算 / 应用题 / 概念理解 / 学习习惯。
- 表达能力：口头表达 / 写作 / 演讲 / 社交沟通。

如果上下文已指向某一分支，就直接推断并记录 evidence，不重复问。

### P0：用户明确事实冲突

例如：

- “6 岁的四年级孩子”
- “人教版北师大教材”
- 当前说二年级，已确认事实中写三年级

问题应直接指出冲突并让用户确认哪一个有效，不要自行选择更常见的答案。

### P0：硬约束冲突

例如：

- “只要免费的，付费课程也可以”
- “不要视频，最好找动画”
- “必须可打印，只想要音频”

确认真正不能妥协的条件。软偏好之间可以并存，不需要澄清。

### P1：学习者信息确实改变内容路线

年龄通常不是第一问，但以下情况值得问：

- 同一主题在低幼和高年级差异巨大，例如性教育、安全教育、编程和历史纪录片。
- 用户要求“孩子自己看”，适龄和安全要求会直接影响候选。
- 需求涉及教材同步，但没有学段或年级。

以下情况不问年龄：

- 已有明确年级。
- 主题可以多年龄覆盖并由 Selector 标注。
- 用户只是先看候选。

### P1：场景会决定资源媒介

只有资源形式会因此完全改变时才问：

- “想找英语材料”但已知场景是开车时使用 → 可直接推断音频，不问。
- “想找亲子活动”但不清楚是在家操作还是课堂使用 → 场景可能决定材料类型，可问。

## 3. 不应该澄清的情况

- "四年级数学课程"——主题和年级已经足够，"课程"已隐含视频/教学形态。
- "恐龙科普，形式都可以"——Intent 记录用户明确接受不限形态，由 Search 规划多形态搜索。
- "推荐几个英语启蒙资源"——先用标准模式搜索，语言和形式可保持开放。
- "你看着办""随便推荐"——采用透明默认，不要把决定权退回用户。
- "最好官方"——这是 prefer，不需要确认是否完全排除非官方。
- 没指定平台——平台路由属于 Search。
- 没指定数量——搜索预算属于 Search。
- 没指定下载格式——可在 Selector/Downloader 阶段处理。
- "找几道练习题""想要试卷"——用户已说清要文档/练习类，不需要问形态。
- "找三年级数学视频/动画/课程"——用户已指定形态，不需要问。

## 4. 一次只问一个问题

错误：

> 孩子几岁、几年级、想学什么、喜欢视频还是音频、要不要付费？

正确：

> 现在最想解决的是计算、应用题，还是数学概念理解？

即使存在多个未知信息，也只问影响最大的一个。用户回答后重新运行 Intent，再判断是否还存在 P0 歧义。

## 5. 问题表达

问题应包含：

1. 用户能理解的自然语言。
2. 当前最可能的 2-3 个方向，帮助快速回答。
3. 允许自由回答，不强迫选固定分类。

示例：

- “你说的编程更偏向 Scratch 动画、Python 入门，还是机器人编程？”
- “孩子数学跟不上，当前最困扰的是计算、应用题，还是课堂概念理解？”
- “你提到 6 岁和四年级，这两个信息不太一致，以哪个为准？”
- “你说不要视频但希望有动画，实际是完全不要视频，还是可以接受短动画讲解？”

不要说“请补充槽位”“请选择资源分类”“为了精准推荐请填写以下信息”。

## 6. 澄清结果结构

```json
{
  "data": {
    "status": "needs_clarification",
    "clarification": {
      "question": "你说的编程更偏向 Scratch 动画、Python 入门，还是机器人编程？",
      "reason": "当前表达对应三种不同学习路线"
    }
  }
}
```

`reason` 解释为什么必须问。已有槽位已经表达当前掌握的信息，不再额外维护 ambiguity 和 missing-information 列表。

## 7. 两轮上限

- 第一轮解决 P0 核心问题。
- 第二轮只处理仍然会导致路线错误的冲突。
- 两轮后，非关键未知项继续省略并进入下一阶段。
- 两轮后核心学习对象仍无法形成，返回无法规划，不得编造主题。

## 8. 最终检查

提出问题前检查：

1. 这个问题是否真的会改变搜索资源类别？
2. 是否可以通过多形态召回和 Selector 选择解决？
3. 是否误把缺少平台/形式/数量当成必须澄清？
4. 是否一次问了多个问题？
5. 是否已有上下文证据可以回答？
