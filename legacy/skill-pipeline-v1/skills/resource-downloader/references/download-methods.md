# 下载方法与路由

本文只说明统一执行器的路由边界。正常流程不要让模型手工拼接 `curl`、`wget`、`yt-dlp`、`ffmpeg` 或平台命令；所有下载都通过 `scripts/run_download_plan.py`。

## 自动路由

`strategy=auto` 按以下顺序执行：

1. 当前资源存在适用的平台单资源入口时，执行平台下载器。
2. URL 或响应表现为独立文件时，执行通用文件下载。
3. 普通公开网页保存 `source.html`、`content.md` 和 `metadata.json`，作为 Level 2。
4. 前述方法均失败且允许元数据兜底时，保存 `source.md`，作为 Level 3。

模型通常不覆盖自动路由。只有用户明确要求某种结果，或已经确认 URL 是文件直链时，才显式选择 `platform`、`direct`、`webpage` 或 `metadata`。

## 通用文件下载

- 只接受绝对 `http/https` URL，并限制重定向协议、超时和最大字节数。
- 优先使用响应中的文件名；没有文件名时根据 URL 和 `Content-Type` 生成。
- 下载后检查文件魔数、容器结构、扩展名一致性和明显 HTML 错误页。
- 当前识别 PDF、EPUB、ZIP、DOCX、XLSX、PPTX、常见图片、音视频、压缩包、旧 Office 容器和文本。
- 文件先进入 `.partial/`，全部校验通过后才原子提交。

## 网页归档

- 只处理公开 HTML 页面，不执行页面脚本，不模拟登录，不处理验证码。
- 保存原始 HTML、清理后的 Markdown 正文和抓取元数据。
- 提取标题、段落、标题层级、列表和链接；忽略脚本、样式、导航及常见噪声区域。
- 当前不下载页面内图片，也不使用浏览器渲染。动态页面正文不足时继续降级为元数据。

## 平台下载器

平台入口统一位于 `scripts/platforms/`，接口见 `platform-download-contract.md`。平台脚本只负责一个已选资源，不负责搜索、推荐、最终降级或归档。

当前统一执行器支持：

| 平台 | 能力 |
|---|---|
| `bilibili` | 单视频或页面对应资源下载，按安全运行环境提供 Cookie/CDP |
| `cctv` | 官方公开视频 API 与未加密点播 HLS，拒绝直播、加密或受保护内容 |
| `douyin` | 单视频下载，按安全运行环境提供 Cookie/CDP |
| `smartedu` | 教材、课程文件与媒体下载 |
| `zhihu` | 公开回答、文章和相关正文保存 |
| `nlc` | 国家图书馆阅文公开 EPUB 下载 |
| `open163` | 网易公开课公开视频 MP4；仅有 HLS 时需要本机 `ffmpeg` 且拒绝加密流 |
| `yixi` | 一席公开 MP4 或未加密点播 HLS；无视频时可保存公开完整文稿并标记 Level 2 |

平台没有单资源入口、入口不适用于当前资源类型或所需访问条件缺失时，由 `auto` 转入网页或元数据降级。

## 安全边界

- 凭据只来自环境变量或已有安全会话，不写入计划、日志或结果。
- 不绕过登录、付费墙、DRM、验证码、地区限制或站点访问控制。
- 不接入代理轮换、验证码求解、行为模拟或 TLS/WAF 绕过。
- 不把失败页面、空文件、损坏容器或未完成分片标记为成功。

## 扩展新平台

1. 在 `scripts/platforms/` 增加符合契约的单资源脚本。
2. 在 `run_download_plan.py` 注册平台，并限制入口适用的 `resource_id` 或资源类型。
3. 添加夹具测试；公开接口稳定时再增加真实网络冒烟测试。
4. 不修改 Stage 3/4 公共字段，除非搜索层必须产生新的可下载资源 ID。
