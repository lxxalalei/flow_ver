# 交付汇报模板

任务结束时，最终回复至少包含以下信息；不要求机械照抄标题，但不得遗漏实质内容。

## 完成内容

- 做了什么。
- 哪些关键文件发生变化。
- 对行为或架构有什么影响。

## 验证

- 执行的测试、lint、类型检查、语法检查或 smoke test。
- 每项验证的结果。
- 未能执行的验证及原因。

## 计划状态

- 本次计划是否全部 `completed`。
- 若存在 `blocked`，说明阻塞证据、影响和继续所需条件。

## 风险与下一步

- 已知但未解决的风险。
- 明确没有执行的破坏性、联网或生产动作。
- 最有价值的下一步。

只读任务也必须明确写明：“本轮只读，未修改工作区”。
