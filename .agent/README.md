# `.agent` 工作目录

这里保存供后续 Agent 使用的工作过程规范，不保存产品运行状态。

## 内容

- `plans/`：跨文件、多步骤或跨会话任务的执行计划。
- `REPORT_TEMPLATE.md`：任务结束时的交付汇报模板。

产品运行数据必须放在 `.openclaw-test/` 或由服务配置指定的位置，不得放入 `.agent/`。

## 执行规则

1. 开始前读取根目录 `AGENTS.md` 和相关计划。
2. 检查工作树，区分既有修改和本次修改。
3. 多步骤任务先建计划，并保持只有一个 `in_progress`。
4. 执行过程中及时更新状态。
5. 结束前运行适用验证，将本次已完成步骤全部改为 `completed`。
6. 最终回复必须按 `REPORT_TEMPLATE.md` 说明改动、验证、计划状态和剩余风险。
