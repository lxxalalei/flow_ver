# Learning Resource Flow 使用说明

> 面向**最终使用者**：在 OpenClaw 对话里搜索、比较、下载并整理学习资源的人。
> 本文只讲怎么用、结果去哪了、出问题时怎么办，不涉及内部实现与安装部署。
> 适用版本：education-resources 0.5.0（2026-09-07）。

---

## 1. 它能做什么（30 秒版）

在 OpenClaw 的新建对话里直接用**自然语言**描述学习目标即可：

- 按主题跨平台找资料：视频、图文、音频、题库、公开课、教材都可以；
- 在专门平台内搜索：Bilibili、抖音、知乎、国家中小学智慧教育平台（SmartEdu）、CCTV、喜马拉雅、一席、网易公开课、LibGen / Z-Library 找书等；
- 完整展开一个**创作者 / 合集 / 专辑 / 课程 / 教材**，列出全部内容再挑选；
- 把任意**网页保存成离线资料**（含清洗正文）；
- **下载**视频、文档、PDF、课程包，并整理归档到本地学习资料库；
- 只有真实需要时才引导你登录平台，登录态本机加密保存、后续自动复用。

你不需要记住任何技能名、工具名、平台代号或命令行。**描述目标即可，Agent 负责规划、判断与选择，工具负责真实的搜索、下载与归档。**

## 2. 快速上手

打开 OpenClaw 对话，直接说：

```text
帮我找适合小学三年级学习太阳系的中文图文资源，先搜索，不要下载。
```

看到候选后继续选：

```text
把第二个下载下来。
```

下载成功后 Agent 会**建议一句话归档分类**（例如“建议归档到 04-自然科学 / 天文与宇宙，需要就说一声”），确认后才会执行整理。

四条使用原则：

| 原则 | 说明 |
| --- | --- |
| 只说“搜索 / 先看看”就**不会**下载 | 下载、保存、归档都属于副作用，只有你表达意图后才发生 |
| 表达可以简单 | “第 2 个”“这两个”“刚才那个作者的视频”都能承接，指代你已看到的候选 |
| 关键条件先说清 | 给谁用（年级/背景）、要什么形式（视频/图文/练习/可打印）、明确排除什么 |
| 不需要记忆 | 不记技能名、工具名、平台代号；平台想不起名字就说特征，Agent 会确认 |

## 3. 典型问法速查

| 我想… | 可以这样说 |
| --- | --- |
| 找一组主题学习资料 | 帮我找适合初中生理解火山形成过程的资料，视频、图文和练习题都可以。 |
| 只看某个平台 | 帮我找 Bilibili 上讲高中函数单调性的优质视频。 |
| 找国家智慧教育平台的课 | 在智慧教育平台上找人教版小学数学三年级上册的同步课。 |
| 某创作者的全部作品 | 把这个 UP 主主页上的所有视频都列出来：<链接/名字>。 |
| 展开一个合集再挑 | 把这个合集里每一集都展开，我先看看标题再决定下哪些。 |
| 找书 | 帮我找《呐喊》的初版扫描本 / 找一本书：作者、书名或 ISBN。 |
| 网页存成离线资料 | 把这个网页保存成方便离线阅读的资料：https://example.com/article |
| 下载并归档 | 把第二个下载下来，整理到我的学习资料库里。 |
| 只下载某格式 | 把这一课下载成 mp4 保存（或：只要 PDF）。指定格式不存在会如实告诉你，不会悄悄换格式。 |
| 处理长任务 | 把这个课程的全部课时都下载完（几百个文件的任务在后台跑，可随时问进度或叫停）。 |
| 查看 / 删除平台登录 | 检查一下各平台的登录状态 / 把 Bilibili 的登录删掉。 |

## 4. 一次会话里会发生什么

```text
你的描述
  → 理解目标（必要时只问 1 个真正影响方向的问题）
  → 设计互补的搜索路线（讲解类 / 练习类 / 观察类可以同时找）
  → 展示候选：标题 / 来源 / 真实链接 / 为什么值得选
  → 对高潜候选做必要检查（是不是资源本体、能否下载、是否需要登录）
  → 你选择 → 下载 / 归档
```

几个对话中会遇到的词：

| 词 | 含义 |
| --- | --- |
| 展开（Expand） | 把一个容器（合集 / 创作者主页 / 专辑 / 课程 / 教材）完整拆成全部子项 |
| 检查（Inspect） | 确认候选的真实内容、格式、可获取性，而不是凭标题猜 |
| 后台任务（Job） | 下载、大规模展开在后台执行；可查询进度、中途取消 |
| 登录会话（Session） | 某个平台的可复用登录态，本机加密保存 |
| 学习资料库 | 归档下载文件的本地目录（见第 7 节） |

**为什么它有时会继续搜索，有时只问一个问题？**

Agent 按“还缺什么实质价值”判断：你说要“理解机制”，它发现目前只有题目解析，就会再补一轮搜索；当结果已经足够你选择时它就停止，不凑轮数。只有不同答案会明显改变它去找什么时，它才提问（例如“一年级数学”是要同步讲解、基础练习还是趣味拓展）。

## 6. 登录：什么时候要、怎么给、怎么删

**只在真实需要时才登录。** 某个资源操作确实返回需要登录时，正常情况下 Agent 会主动完成除“你本人登录”以外的流程：

1. Agent 自动打开该平台的可见登录页面；
2. 你在这个窗口里用自己的方式完成登录：**扫码**或输入**账号密码**；
3. 登录完成后告诉 Agent 一声，Agent 会从同一个浏览器会话捕获登录状态并保存，不需要你复制粘贴 Cookie、Token 或其他会话数据；
4. 保存成功后 Agent 自动继续刚才被登录阻塞的搜索、检查、展开或下载。

如果当前 OpenClaw 会话无法拉起或控制浏览器，Agent 会明确说明限制并给出可执行的回退方式；不会静默跳过你明确指定的平台或资源。

要点：

- 你在对话里随时可以问“各平台登录状态怎么样”，也可以说“把抖音的登录删掉”来登出；
- 登录态用 Windows 当前用户的 DPAPI 加密保存，**不保存账号密码**；Z-Library 只保留验证所需的两个 Cookie 字段；
- 平台登录态过期时，Agent 会重新打开登录流程；完成登录后继续原任务；
- 智慧教育、LibGen、书格、CCTV、一席等免登录来源不需要任何会话。

## 7. 文件都去哪了

**学习资料库**默认位于 Windows 当前用户的“文档”目录下：`学习资料库`。常见路径为 `%USERPROFILE%\Documents\学习资料库\`；如果你的“文档”目录被重定向到 OneDrive 或其他位置，以 Windows 实际“文档”目录为准。

```text
学习资料库/
├── 01-语文与中文/
│   └── 古诗词/            ← 领域 / 主题 两级
├── 02-数学与思维/
├── 03-英语与外语/
├── 04-自然科学/
├── 05-人文与社会/
├── 06-信息科技/
├── 07-艺术与审美/
├── 08-体育与健康/
├── 09-学习方法与通用能力/
├── 10-综合实践与跨学科/
├── 11-国学经典/
└── 99-待分类/             ← 信息不足时先放这里
```

归档 = 把已下载的真实文件**移入**资料库对应目录。领域与主题由 Agent 提议、你确认；同一主题已有目录时会优先复用，不新建近似目录。

**下载但尚未归档的文件**在数据目录的 job 文件夹里。Windows 一键安装脚本的默认路径为：

```text
%LOCALAPPDATA%\LearningResourceFlow\data\jobs\<job_id>\
  request.json   下载了什么
  worker.log     过程日志
  job.json / results.jsonl   状态与结果
  ...下载产物（视频 / PDF / 网页等）
```

`%LOCALAPPDATA%` 通常为 `C:\Users\<你的用户名>\AppData\Local`。部署方也可以在配置中把数据目录改到其他位置。

新对话里找不到下载位置时，直接让 Agent 帮你定位即可。

**网页离线化**产生四个文件：

```text
source.html     原始 HTML 响应（第一手存档）
content.md      清洗后的正文 Markdown
index.html      离线阅读页（稳定排版，开箱即读）
metadata.json   标题 / 来源 / 抓取信息等元数据
```

说明：网页保存面向“离线阅读正文”，不克隆整站及所有 CDN 图片/脚本资源；抓取上限内如实成功，超限会明确失败而不是给你一份看起来完整实际被截断的副本。

## 8. 常见问题（FAQ）

**Q1：提示需要登录，我该做什么？**
正常情况下 Agent 会自动打开登录页。你只需要在打开的浏览器窗口完成扫码或账号登录，完成后告诉 Agent“登录好了”，它会保存登录态并继续刚才的任务。只有浏览器能力不可用时，才需要按 Agent 给出的回退步骤处理。

**Q2：平台搜不到结果，或之前能搜现在不行了？**
多为平台侧风控、登录墙或 IP 限制。先换一种说法重试；结果仍异常时以工具真实返回的说明为准。平台状态不归本地软件控制，会随时间波动。

**Q3：下载到一半失败 / 中断了？**
告诉 Agent 重新发起该任务即可；网络或平台抖动导致的失败会以真实错误呈现，不会留下“看似完成”的假文件。已归档到资料库的文件不受影响。

**Q4：几百条的合集/创作者列表要等很久吗？**
展开与下载在后台执行，你可以继续聊天或离开；随时问“进度怎么样”或“取消这个任务”。大规模任务结束后 Agent 会汇报哪些成功、哪些失败。

**Q5：指定格式下载会怎样？**
直接说“下成 mp4 / 只要 PDF”。该格式真实存在就按其下载；不存在则如实告知失败，不会悄悄换成别的格式或静默忽略你的要求。

**Q6：新开对话后，之前下载的东西还在吗？**
归档进学习资料库的文件一直在。进程内临时的资源编号只在当时有效；新对话中让 Agent 根据可见的链接、标题等真实信息重新定位同一资源即可。

**Q7：网页保存出来“不完整”是坏了吗？**
不是。离线化保存的是页面正文与原始 HTML 快照（第 7 节），不是浏览器级整站克隆；动态加载、登录后才能看的富媒体不属于保存范围。

**Q8：这个能力会上传我的数据吗？**
搜索、下载、会话都只在你明确发起时发生；登录态只存本机并加密（第 6 节、第 9 节）。下载本身是向对应平台请求公开或你已授权的内容。

## 9. 隐私与数据口径

- 下载产物、归档资料库、搜索缓存都保存在本机；
- 平台登录态使用 Windows DPAPI 加密，仅存本机；不保存账号密码；
- 只向平台侧发出你明确要求的请求（搜索你输入的关键词、下载你选中的资源）；
- 面向 Z-Library 等第三方站点的行为受该站点条款约束（个人账号额度、镜像可用性），本工具不绕过任何账号限制。
